# 제주 진료 나침반 기능 파이프라인

작성일: 2026-10-31 · 상태: 원격협진과 전화 대행을 반영한 현재 설계

**제주에서 받는 대면 진찰과 도외의 기존 주치의·전문의 협진이 이어지도록, 기록 정리부터 전화 문의·자료 보완·회신·후속 일정까지 진행하는 Agent.**

환자와 가족이 시작하고, 의료진이 진찰·협진 판단을 담당한다. Agent는 필요한 정보와 담당 창구를 찾아 실제 도구로 문의·정리·추적하고 답변에 따라 다음 작업을 바꾼다. 현재는 설계 단계이며 실제 의료기관 참여나 전화·기록 전송 연동을 확보한 상태는 아니다.

## 1. 시작 상황과 입력

예시:

> “제주에 살고 있고 서울의 기존 주치의에게 추적 진료를 받고 있습니다. 제주에서 진찰받은 내용을 주치의에게 전달해 협진할 수 있는지 알아보고, 필요한 서류와 일정을 준비해 주세요.”

암 치료 후 추적 진료는 검토 중인 예시다. 첫 시연의 구체 암종·치료 단계는 아직 정하지 않았다. 정형외과 수술 후 일반 외래 사례를 현재의 확정 대표 사례로 두지 않는다.

입력은 기존 치료 병원·주치의·진료과, 사용자가 가진 진료기록·검사 판독문·이미 안내받은 계획, 제주 출발지·이동 조건, 보호자 가능일, 전화·정보 전달을 위임할 범위다. 진찰 소견과 새로운 검사 결과는 실제 수행한 의료진의 기록으로 받는다.

## 2. 단계별 동작

| 단계 | Agent가 할 일 | 사용자·의료진의 역할 | 남길 결과 |
| --- | --- | --- | --- |
| 1. 요청과 범위 확인 | 기존 병원·목적·일정·보유 자료와 전화·공유 범위를 구조화하고 빠진 조건 질문 | 환자·보호자가 입력과 위임 범위 확인 | 사례 카드와 허용 범위 |
| 2. 기록·근거 정리 | 진단·치료·검사·현재 보고 상태를 출처와 함께 요약. 용어·근거 문헌과 의료진에게 물을 질문 정리 | 사용자가 사실 오류 수정, 의료진이 임상 내용 검토 | 의료진용 요약 초안과 누락 정보 |
| 3. 기존 도외 병원에 전화 문의 | 협진 창구, 접수 대상, 의사 명의 의뢰 필요 여부, 사전 검토 자료·회신 경로·일정 조건 확인 | 도외 기관이 운영 절차 안내. 환자별 협진 가능 여부는 해당 의료진이 판단 | 기관이 요구한 준비 목록과 검토 상태 |
| 4. 제주 후보 조회와 전화 확인 | 제주 공공데이터에서 기관·주소·진료과 후보 조회. 공식 번호로 해당 협진 참여·접수·자료 전달 조건 문의 | 제주 기관이 참여·진료 범위 검토, 사용자와 의료진이 후보 확인 | 확인된 제주 창구와 가능한 일정안 |
| 5. 현지 진찰과 자료 준비 | 의료진·기관이 정한 항목으로 체크리스트 생성. 기록·판독문·첨부의 보유·누락 확인, 의뢰 자료 초안 준비 | 제주 의사가 대면 진찰하고 필요한 검사를 결정·수행. 의료진이 소견·의뢰 내용 확인 | 확인된 진찰 소견과 협진 자료 묶음 |
| 6. 도외 전문의 협진 | 승인된 기관 절차에 따라 제출을 지원하고 수락·추가 자료·회신 상태 추적. 지원되는 기존 화상 도구의 일정 연결 | 도외 전문의가 자료를 검토하거나 영상으로 협진. 두 의료진이 추가 진찰·직접 방문·후속 관리 판단 | 출처가 있는 의료진 회신 |
| 7. 실행 계획과 부담 계산 | 확정된 회신을 검사·외래·자료 전달·동행 작업으로 전환. 확인 가능한 의료비·교통·숙박·시간·동행 공백 계산 | 사용자·의료진이 실행 조건 확인. 예약은 실제 확정 근거에 따라 상태 변경 | 환자·가족용 일정과 비용 내역 |
| 8. 보완과 변경 추적 | 자료 요청·일정 변경·미회신을 감지하고 허용 범위에서 재문의·보완·재계산 | 새 정보 전달이나 의료적 변경은 해당 권한자의 확인 | 다음 행동이 정해진 최신 진행 현황 |

공공데이터의 기관 등록·진료과목만으로 협진 참여나 개별 환자의 진료 적합성을 확정하지 않는다. 문의에 필요한 공식 전화번호와 실제 참여 가능 여부는 별도로 확인한다.

## 3. 진행을 바꾸는 응답

| 받은 답변·상황 | 다음 동작 |
| --- | --- |
| “담당 의사의 의뢰가 필요합니다” | 의료진 확인·작성 작업 생성. Agent가 의사 명의로 의뢰서를 발행하지 않음 |
| “최근 검사 판독문과 현지 진찰 소견이 필요합니다” | 보유 자료와 대조. 기존 기록 누락은 취득 절차를 확인하고, 아직 하지 않은 진찰은 의료진 일정에 연결 |
| “추가 자료를 검토한 뒤 답변하겠습니다” | 추가 자료 대기로 유지하고 요구 항목·담당·회신 경로 추적 |
| 의료진이 현지 진료와 원격 검토 범위를 정함 | 그 범위로 제주·도외 방문과 자료 전달 계획 생성 |
| 의료진이 도외 대면 방문 필요성을 회신 | 방문 준비·자료·가족 동행·이동 계획으로 연결 |
| 병원이 협진에 참여하지 않거나 전화가 연결되지 않음 | 운영상 미확인·미참여로 기록. 이를 도외 진료의 의학적 필요성으로 바꾸지 않음 |
| 보호자 동행 불가·기관 일정 변경 | 영향을 받는 작업·동행 공백·비용·시간만 재계산. 진료 계획의 변경이 필요하면 의료진 확인 작업 추가 |

핵심 반복은 **답변 수신 → 누락·상태 확인 → 다음 도구·담당 작업 선택 → 보완 → 다시 확인**이다. 통화와 자료 전송을 했다는 이유만으로 협진 완료나 예약 확정을 선언하지 않는다.

## 4. 의학적 근거와 비용 비교의 위치

논문·가이드라인은 기록을 이해하고 의료진에게 확인할 질문과 참고 근거를 준비하는 데 사용한다. 환자별 진료 장소, 협진의 충분성, 검사·치료 변경은 의료진이 판단한다. 근거를 임상 판단에 직접 적용하는 별도 기능은 기존의 규제·임상 검토 대상으로 남긴다.

비용·시간 비교는 의료진이 제시하거나 검토한 선택지의 실행 부담을 설명한다. 제주에서 가능한 항목과 도외 방문이 필요한 항목을 의료진이 나누면 그에 따라 방문별 부담을 계산한다. 사용자가 횟수를 바꾸어 보는 경우에는 가정임을 표시한다.

한국의 급여 기준·환자 보험 조건·병원 견적을 연결해 의료비 본인부담을 항목별로 검토하고, 교통·숙박·보호자 이동·동행 비용과 분리해 합산한다. 적용 조건이나 금액이 확인되지 않으면 미확인으로 남기고 현재 계산 가능한 소계만 제시한다.

## 5. 결과물

- **의료진용 협진 자료:** 출처가 연결된 기록 요약, 실제 진찰 소견·판독문, 질문과 확인된 첨부 목록.
- **협진 진행 현황:** 창구·기관 참여, 의료진 검토, 누락 자료, 회신과 예약 상태, 다음 담당·작업.
- **환자·가족 실행 계획:** 어디에서 언제 무엇을 해야 하는지, 준비 서류·동행, 계산 가능한 비용과 남은 미확인 항목.

처음에는 단일 ‘추천 병원 점수’보다 각 단계에서 확인된 조건과 다음 행동을 보여준다. 의료진 회신이 오기 전에도 전화로 확인한 준비 절차와 필요한 작업을 제공할 수 있다.

## 6. 첫 시연 범위

합성 환자 1명, 도외 기존 치료 병원 역할 1곳, 제주 후보 역할 1곳, 협진 요청 1건으로 시작한다. 테스트 통화에서 추가 자료를 요청받고, 실제 보유 여부를 확인해 준비 목록과 진행 상태를 바꾸며, 의료진 역할의 회신 후 일정·부담 계산이 갱신되는 흐름을 완성한다.

실제 전화망 연결은 협조받은 테스트 번호로 검증한다. 의료진 역할의 합성 회신과 실제 의료기관의 판단을 표시에서 구별한다. 외부 병원 EMR 자동 접근, 임의 전문의 연결, 실시간 화상진료 플랫폼 자체 개발을 전제로 두지 않는다. 기록 제출은 기관의 허용된 경로로 지원하고 연동이 없으면 제출 자료 준비·사람의 전달 상태를 관리한다.

첫 시연에서 검증할 것은 질문 해석, 실제 도구 사용, 누락 자료 탐지, 답변에 따른 작업 전환, 비용·일정 재계산이다. 실제 협진 운영과 임상적 유효성은 참여 의료진과 별도로 검증한다.

근거와 제약은 [데이터·출처 명세](data-sources.md), [원격협진·전화 대행 조사](../research/remote_collaboration_cases_2026-10-31.md)에 정리했다. [PRD v0.2](prd.md)는 기관 선택 비교와 정형외과 사례를 기준으로 작성한 이전 요구사항이며, 현재 흐름에 따른 세부 요구사항은 다음 개정 때 통합한다.
