# 제주 데이터와 문의 준비 화면 계약

확정일: 2026-11-16. 사용자의 제주 데이터 적극 활용 요청에 따른다. 지역별 좌우 진입·독립 초안은 유지하고, 제주 기본 진입을 공개 등록 병원 탐색으로 바꾼다. `region-booking-contract.md`의 제주 가상 병원 기본 진입보다 우선한다.

## 사용자 흐름

1. 제주 병원 → 지역·등록 진료과 → 실기관의 문의 준비.
2. 월간 달력에서 희망 하루/기간과 오전·오후·무관 선택. 한국 날짜 기준 오늘부터 다음 해 같은 달까지 탐색한다. 빈자리·휴진·의료진 상태를 표시하지 않는다.
3. 문의 준비표에 기관 사실과 사용자의 희망을 구분해 표시한다. 실제 접수·의뢰서 등 필요 서류·의료진과 시각은 기관 확인으로 남긴다.
4. 제주 이동·동행에서 차량/동행·돌봄/공공보건 문의처를 명시적으로 선택한다. 서울 경로도 제주공항 출발·귀가 후 지원에 같은 화면을 쓴다.
5. 선택된 근거와 전화·출처를 Markdown 준비표에 저장한다. 외부 전화·문의·예약·발신·전송은 실행하지 않는다.

## 상태와 구현

- `app/jeju-appointment-data.js`: 공개 snapshot과 기존 `filterHospitals`, `getSupportCandidates`, `getPublicHealthContacts`를 재사용한다. 실기관에 임의 의료진·일정을 생성하지 않는다.
- `app/appointment-demo.js`: `usePublicData`, `jejuHospital`, `jejuSupport`. 공개 경로는 synthetic slot/request/reply 액션을 거부한다. 모드 왕복 시 각 선택을 보존하지만 이동 체크는 재확인으로 돌린다. 공개 경로의 이동 시각 대조에는 가상 진료 시각을 가져오지 않는다.
- 병원 지역/등록 과목 변경은 병원 선택·준비 완료를 해제한다. 날짜·시간대·병원 변경은 이동 체크를 해제한다. 달 이동만으로 희망 날짜를 지우지 않는다.
- 지원 검색 지역 변경은 세 문의처 선택·이동 체크를 해제한다. 휠체어 조회 조건은 유지한다. 휠체어 조건 변경은 차량 선택·이동 체크를 해제한다. 원래 환자 상태·주소·동의·기본 설정은 바꾸지 않는다.
- `web/components/jeju-public-booking.jsx`, `jeju-support-contacts.jsx`: React/shadcn 행 목록·월간 달력·선택 컨트롤. 흰 작업면과 출처 펼침을 사용한다. 숫자 홍보 카드나 좌측 강조 막대를 추가하지 않는다.
- 기존 대화/AI 공공데이터 도구·합성 preview·DB·Prompt는 변경하지 않는다. 화면은 모델/API 호출 없이 동작하며 새로고침하면 임시 선택이 사라진다.

## 남는 범위

병원 표본은 2024-10-17 수집이며 전체 제주 목록이나 현재 운영·접수를 보장하지 않는다. 등록 진료과는 임상 적합성 판단이 아니다. 병원 전화번호·실시간 의료진·빈자리는 보유하지 않는다. 센터 도로·교통량은 명세만 확인했고 raw 데이터 미접근이므로 거리·ETA·교통 추천 점수를 계산하지 않는다. 허브 목록과 센터 명세를 조회한 사실을 전체 원자료/API 확보로 확대하지 않는다.
