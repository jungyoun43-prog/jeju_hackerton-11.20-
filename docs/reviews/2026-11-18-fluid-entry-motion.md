# 해상도별 진입 비율과 전환 효과 · 2026-11-18

## 변경

직전 고정1,440px 영역은 큰 해상도에서 화면 대비 작아지는 한계가 있었다. 지역·입력 방식 선택의 가용 너비와 높이를 함께 읽어 제목·설명·여백·CTA 크기를 같은 비율로 바꾼다. 범위는 최소16px·최대44px 기준 단위이며 카드 높이는 내용에 따른다. 브라우저 zoom·페이지 전체 transform·입력 글자 축소는 쓰지 않는다. 520px 이하의 두 행과 작은 창의 내부 읽기 스크롤을 유지한다.

Impeccable의 adapt/animate, Animate, Make Interfaces Feel Better의 animation/performance 지침을 참고했다. 기존 `--feedback-ease`, CSS, Web Animations API를 사용하며 라이브러리는 추가하지 않았다.

- 지역·방식 선택: 클릭 위치에서 새 제목으로 감귤이 이동하고 파동·색 조각6개가 사라진다. 주 효과620ms, 목록 순차 간격40ms·총 지연120ms 이내.
- 일반 단계: 방향을 보여주는280ms 전환. 다음 화면·초점은 먼저 바뀌며 효과가 행동을 기다리게 하지 않는다.
- 일반 버튼:160ms 눌림과280ms 클릭 파동. hover 이동은 정밀 포인터에서만 실행한다.
- 키보드: 공간 이동 없이 즉시 전환. reduced motion: 비행·조각·이동을 생략하고 제목을140ms로 강조한다.
- 연속 입력·탭 숨김·설정 변경: 이전 효과를 취소한다. 장식 DOM은 `aria-hidden`·`pointer-events:none`이며 환자·음성·예약 상태를 변경하지 않는다.
