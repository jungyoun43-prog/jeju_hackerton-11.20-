# 제주 데이터의 화면 활용과 공식 평가기준 확인

확인일: 2026-11-16. Ego Lite의 공개 페이지 본문을 읽었다. 검색 스니펫·HTTP200만으로 확인하지 않았다. 로그인·제출·실제 기관 연락은 하지 않았다.

- [대회 공식 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)의 평가 기준을 펼쳐 확인했다. 필수 데이터 활용 적절성 20점은 지정 데이터 1종 이상의 실질적 사용과 처리 적절성을 평가한다. 나머지는 주제15·Agent25·편의/실용25·신뢰/재현15점이다. 전문가70%·상호평가30%를 안내한다. 이 구현의 점수나 합격을 확인한 것은 아니다.
- 사용자 지정 [허브 목록](https://jejudatahub.net/data/list/12) 본문에서 전체1,259·보건복지198, 데이터 유형과 목록을 확인했다. 이는 카탈로그 관측수다.
- 사용자 지정 [센터 제공데이터](https://jejudatahub.net/center/data) 본문에서 버스 노선·정류소·이용 현황과 데이터 명세서 접근, 반출 가능/불가능 표기를 확인했다. raw 데이터 다운로드·접근 권한 확보를 뜻하지 않는다.

본문 관측: `output/jeju-data-qa/official-rubric.txt`, `official-hub-list.txt`, `official-center-data.txt`. 이번 페이지 확인에서 새 원자료를 수집·갱신하지 않았다. 기존 저장본의 자료 기준일·취득일·권리 표시는 유지했다.

## 평가자가 직접 재현할 흐름

제주 병원 → 제주시·정형외과 선택: 13개 보유 표본 중 등록 과목이 일치하는 3곳으로 좁혀진다. 제주우리병원을 고르고 날짜 또는 기간·시간대를 남긴다. 제주 이동에서 애월 조회는 애월콜·애월보건지소를 먼저 보여준다. 휠체어 조건은 공식 이동지원센터를 우선하고, 한경면으로 바꾸면 한경보건지소가 먼저 나온다. 서귀포 보건 조회는 제주시 파일의 범위 밖임을 설명한다. 선택한 문의처와 근거·기준일·출처가 준비표에 남는다.

이 흐름은 데이터 필드 → 필터/정렬 → 달라진 문의 대상 → 출처가 남는 결과를 보여준다. 실시간 데이터·AI 임상 판단·운영 예약의 성능을 입증하는 시연은 아니다. 상세 동작은 [구현 계약](../docs/jeju-data-booking-contract.md)을 따른다.
