# 입력·실시간 음성·화면 비율 확인 · 2026-11-17~18

## 반영한 흐름

제주/내륙 → 말로/글로/하나씩 → 내용 확인 → 빠진 조건 선택으로 이어진다. 요청 예시 두 개를 기본 표시하며 클릭은 기존 초안에 추가만 하고 모델 호출이나 제출을 하지 않는다. 입력 중 네 조건은 사용자 희망을 표시하며 예약 완료나 임상 판단이 아니다. 월간 달력, 병원·진료과 검색, 출처와 실제/시연 구분을 유지했다.

Impeccable의 clarify/onboard/layout 기준으로 현재 행동과 다음 단계의 위계를 나눴다. 주황은 실제 다음 단계, 초록·윤곽선은 같은 화면 선택, 뒤로·수정·상세는 보조 행동이다. 제주고딕은 제목, Pretendard는 본문과 조작에 사용한다. 사진 위 투명 레이어는 후속 피드백으로 제거했다.

## 버튼 비율 수정 · 11월 18일

사용자가 제공한 큰 화면에서 카드에 비해 글자와 행동이 지나치게 작았다. Ego Lite 실제 2,831×1,448 CSS px 창에서 수정 전 카드 높이 약 1,175px, 내부 CTA 폭 약 1,197px를 관측했다. `height:100%` → 가운데 `1fr` → 카드 높이와 `space-between`의 연쇄가 원인이었다.

- 지역·방법 화면은 내용 높이와 최대 1,440px 묶음으로 구성한다. 남은 높이를 버튼에 배분하지 않는다.
- 제목·설명·목록·행동을 가까이 묶는다. 지역 CTA는 48px 높이·문구 폭으로 표시하고 카드 전체의 클릭 영역은 유지한다.
- 520px 이하에서는 두 지역을 짧은 행으로 배치한다. CTA의 중복 지역명만 생략하며 제목·설명·범위는 유지한다.
- 넓은 요청 화면의 작성 영역은 280px까지 배분해 입력창과 조건 행의 과도한 확대도 막는다.
- 입력·선택·원문·음성 소유권과 예약 상태 로직은 이번 비율 수정에서 바꾸지 않았다.

첫 시각 검사에서 큰 창의 상단 margin이 부모와 겹쳐 불필요한 스크롤을 만들고, 휴대폰 CTA가 두 줄로 벌어지는 것을 발견했다. 최종 수정은 부모의 안전한 중앙 배치와 휴대폰의 행 구성으로 처리했다. 독립 읽기 전용 레이아웃 검토와 기계 검사를 분리했으며, 기계 finding 0건을 미적 품질의 합격으로 해석하지 않았다.

## 실제 API와 음성 확인

크레딧 충전 뒤 최소 Responses 호출은 HTTP200, 4,628ms, 입력20·출력8토큰으로 성공했다. 기존 quota 실패 이력은 삭제하지 않았다. 모델명·추론 설정·키를 제품 화면이나 공개 capabilities에 노출하지 않는다.

OpenAI Realtime 세션 생성은 실제 HTTP200으로 확인했다. 한국어 합성 음원을 사용한 WebRTC 검증에서는 음성 입력5건·음성 출력113,927바이트·끼어들기·조건 업데이트1건을 관측했다. 사람이 실제 마이크로 다양한 환경에서 사용한 품질 검증은 아니다. 같은 서버 키를 사용하며 별도 ElevenLabs 계정을 필요로 하지 않는다.

실제 음성 검사 파일의 `endStatus:null`은 공급자 종료 응답 확인이 남았다는 뜻이다. 클라이언트와 서버의 종료 대기 시간이 같던 문제를 수정해 클라이언트 대기를 8초로 늘렸고 종료 중 재시작을 막았다. 수정 후 unit/fixture 검증은 했으나 추가 유료 세션으로 공급자 종료 HTTP200을 재검증하지 않았다. 성공 표시로 바꾸지 않는다.

일반 Responses 기본 한도는 UTC 하루60시도·요청당6회·출력4,096토큰이다. 음성은 별도 하루3생성 시도·동시1개·세션180초다. 실패 시도도 차감하고 재시작으로 초기화하지 않는다. 호출·시간 한도이며 고정 금액 상한은 아니다. 현재 실시간 엔드포인트는 로컬 Node용이며 AWS에 배포하지 않았다.
