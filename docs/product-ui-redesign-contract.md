# 제품 화면 리디자인 계약 · 2026-11-05

사용자는 현재 화면을 AI slop으로 평가하고 실제 좋은 소프트웨어 여러 곳을 참고해 수정하도록 요청했다. 이전 지문57ea8657/커밋5b6ad99의 표면은 교체하되 승인된 제품 구조·기능·브랜드·한 화면 작업 공간을 유지한다. 디자인과 해커톤 시연의 범위를 구분한다.

## 해커톤 범위

병원·택시·동행의 실제 발신/배차/예약은 대회 MVP 필수 완료 조건이 아니다. 공개데이터가 후보·질문을 바꾸고, 합성 문의 결과·실패 인계·일정 변경이 다음 준비에 이어지는 과정을 시연한다. 가상 사례/합성 결과와 실제 실행 여부는 명료하게 표시한다. 일반 자유 입력의 실제 모델 품질은 별도이며 기존 크레딧 소진 후 추가 유료 호출0을 유지한다.

## 관측한 문제와 방향

현재 화면은 제목3개가 비슷한 크기로 경쟁하고, 중앙/입력/안내/요약의 둥근 프레임과 비슷한 설명이 겹친다. 텍스트 초안을 넣으면 voiceMessage를 통해 전체 안내가 자동으로 열려 실제 할 일을 가린다. 왼쪽 보조 메뉴·오른쪽 단계·세부 여정이 같은 중요도로 보인다.

Operate 화면으로 재구성한다. Things Today의 연속된 작업면·제목/보조정보 위계, Linear Inbox의 간결한 선택 행과 상태 정렬, Attio Tasks/record의 업무·맥락 분리를 참고한다. 공식 페이지/공개 제품 이미지와 실제 관측 한계는 조사 기록으로 남긴다. 마케팅 화면과 로그인 뒤 제품 사용을 구분하며 외부 자산을 복사하지 않는다.

- 왼쪽: 혼디 로고·대상자·선택적 이동 설정·보조 도구. 짧은 탐색과 작은 회색 설명, 과도한 원형 아이콘/반복 화살표/큰 소개 제거.
- 중앙: 현재 실제 할 일이 시각적으로 유일한 대표 제목이다. '지금 준비할 일' 등의 제목은 필요한 접근성 의미를 유지하며 중복 시각 제목을 줄인다. 담당·단계·행동·상세를 한 연속된 흰 작업면에 정돈한다. 매번 큰 인사/숫자타일/꾸민 빈 상태를 만들지 않는다.
- 오른쪽: 같은4단계·기호/아이콘·선택/현재 구분을 유지한 간결한 세로 행. 카드 안 카드 대신 한 탐색면과 얇은 구분선. 현재 업무와 읽기 선택은 별개다.
- 상단: 사례 정보와 보조 도구를 정돈한다. 큰 제목/도구 두 줄의 빈 공간을 줄인다. 넓게 읽기/체험/새 대화는 유지하고 좁은 창에서도44px 접근을 보장한다.
- 입력: 한 textarea/폼과 요청 예시·음성·고지/도움말·중지/오류를 유지한다. 편집 가능한 초안을 넣었다는 피드백은 짧은 inline 상태로 제공하고 전체 개인정보 안내를 자동으로 열지 않는다. 실제 음성 피드백과 전체 안내의 접근 경로·원문은 보존한다.
- 기존 Pretendard 분할 폰트·hondi PNG·주황 이름/주 행동·초록 선택/상태·기존 제주 배경을 재사용한다. 차가운 청회색과 여러 겹 둥근 상자를 밝은 중성 바탕·얇은 선·명확한 글자 위계로 바꾼다. 기존 semantic primary/secondary/soft 색은 유지해 대비와 익숙한 신호를 보존한다. 인물 사진/외부 CDN/의존성/이미지 생성은 추가하지 않는다.
