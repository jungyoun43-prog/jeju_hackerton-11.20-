# 혼디 | 제주와 내륙 진료를 함께 준비하는 AI 에이전트

제주 애월에 사는 어머니의 진료를 서울에 있는 딸이 준비한다고 생각해 보세요. 제주 병원에 가는 날엔 집까지 올 차량과 병원에서 만날 사람이 필요합니다. 내륙 병원에 오시는 날엔 항공편과 공항 마중, 검사 뒤 하룻밤 묵을지도 함께 정해야 합니다. 혼디는 가족이 원하는 조건을 말하거나 적으면 빠진 일을 짚고, 한 방문에 필요한 일정을 모아 보여줍니다. 2026년 11월 19일 제출본입니다.

11월 19일 12:00 한국시간에 공개 앱에서 애월읍 택시 문의처와 기준일을 묻는 합성 질문 한 건을 보냈습니다. 서버가 14.1초 만에 애월콜과 2026-03-19 기준일을 답했고, 실제 배차 가능 여부는 문의 사항으로 남겼습니다. [실행 확인 기록](verification/public-agent.json)

## 최신 예약 화면 실행

ZIP을 모두 풀고 이 README와 `package.json`이 있는 **hondi** 폴더에서 터미널을 엽니다. Windows PowerShell에서는 다음 두 줄을 차례로 실행합니다. Node.js 22.9 이상과 npm, 첫 의존성 설치 시 인터넷이 필요합니다.

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd start
```

브라우저에서 **http://127.0.0.1:4173** 을 엽니다. macOS·Linux에서는 같은 명령의 `npm.cmd`를 `npm`으로 바꿉니다. 실행용 웹 빌드가 `dist/`에 들어 있습니다. 종료는 터미널에서 Ctrl+C입니다.

## 3분 체험

1. **제주 병원 → 글로 요청**을 고릅니다. 화면의 요청 예시를 선택하거나 “제주우리병원 정형외과에 다음 달 오후에 가고 싶어요. 애월읍에서 출발하고 휠체어 차량과 동행이 필요해요”라고 입력합니다. 병원·일정·서류·이동 네 항목에 반영된 조건을 확인하고, 비어 있는 날짜·시각을 선택합니다.
2. **AI에게 맡길 내용**에서 병원·차량·동행을 확인하고 **이 내용으로 예약 시연 시작**을 누릅니다. 기관별 가상 회신이 도착하면 결과창이 열립니다. **내 예약 현황 → 예약 수정**으로 조건을 바꾸거나 결과표를 저장할 수 있습니다.
3. 차량 거절 사례를 보려면 다시 조율할 때 시연 상황에서 차량이 없는 응답을 고릅니다. 결과창에서 대체 출발 시각을 고르면 차량만 다시 조율하고 병원·동행 회신은 보존합니다. [차량 거절 결과표](verification/01-handoff.md) · [대체 차량 조율 뒤 결과표](verification/02-recovered.md)
4. **처음으로 → 내륙 병원 → 하나씩 선택**에서는 병원·진료과를 검색하고 월간 달력에서 하루나 기간을 정합니다. 가상 시간표에서 의료진과 시각을 선택한 뒤 진료의뢰서와 왕복 교통을 확인합니다. 항공편은 선택한 날짜로 가격 비교 사이트에서 조회하며 구매는 해당 사이트에서 진행합니다.

병원 회신을 받은 뒤 **시연 중지**를 눌러도 그 회신은 남습니다. **내 예약 현황**에서 **중지한 조율 이어보기**를 열고 **남은 예약 이어서 조율**을 누르면 차량과 동행부터 계속합니다.

시연의 의료진 시간표와 예약 회신은 가상입니다. 공개 등록자료에 있는 병원과 업체는 연락할 후보로 표시합니다. 숙박은 ‘숙박 또는 다른 날 귀가’로 계획에 남길 수 있습니다. 화면의 예약 현황은 해당 탭에서 유지되며, 새로고침 전에 결과를 파일로 저장할 수 있습니다. [화면별 사용법](docs/user-manual.md)

**전화와 기관 연동을 시연으로 둔 이유**　운영자용 코드에는 전화를 걸어 양방향 음성을 주고받는 경로가 있습니다. 환자의 위임 범위, 기관이 받을 번호와 시간, AI 고지와 통화 정보 처리 방식을 합의해야 실제 회선을 연결할 수 있습니다. 현재 앱은 가상 창구의 회신으로 조율을 보여줍니다. 향후에는 기관의 회신 전화를 받거나 협력 기관의 API를 MCP 도구로 연결해, 합의한 양식으로 택시·공항 지원·숙박을 문의하고 접수 결과를 받을 계획입니다. [전화 코드와 검증 범위](docs/outbound-phone-adapter.md) · [기획 배경과 연동 근거](research/jeju-off-island-care-2026-11-19.md)

## 제출 소스에서 모델을 직접 실행할 때

첫 화면의 **대화·자료 준비 열기**에서 자유 질문을 보냅니다. “애월과 서귀포의 의료·돌봄 등록 자료를 비교해줘”라고 하면 에이전트가 데이터 조회 도구를 선택하고, 코드로 집계한 결과와 관측 범위를 설명합니다. 모르는 조건은 질문으로 돌려줍니다. 서버 운영자가 직접 모델을 연결할 때만 아래 설정을 사용합니다. 심사자는 위의 공개 앱에서 같은 종류의 질문을 바로 보낼 수 있습니다.

서버를 종료하고 `.env.example`을 같은 폴더에 `.env`로 복사합니다. `OPENAI_API_KEY=` 오른쪽에 평가용 키를 넣고 다시 시작합니다. 키·모델·추론 설정은 서버에서만 읽습니다. 키 없이도 위의 예약 시연과 지역별 공개자료 검색을 이용할 수 있습니다.

| 기능 | 사용 기술과 실행 범위 |
| --- | --- |
| 자유 대화 | 기본 OpenAI `gpt-6.1-sol`, 추론 강도 `medium`, Responses API 도구 호출. 허용 도구가 합성 상태와 공개자료를 읽거나 변경하며, 실행 결과를 다음 모델 호출에 전달합니다. |
| 제출 소스의 호출 제한 | 기본 UTC 하루 대화 20턴, 실제 Responses 요청 최대 60회, 한 턴 최대 6회, 호출당 최대 출력 4,096토큰. 로컬 카운터는 재시작 후에도 유지됩니다. |
| 실시간 음성 | 로컬 브라우저 마이크 권한과 인터넷이 필요합니다. OpenAI Realtime으로 음성이 오가며 사용자가 답변 도중 끼어들 수 있습니다. 하루 최대 3세션, 동시 1세션, 회당 최대 3분입니다. |
| 예약 조율 | 고정 시나리오·상태 전이로 시연합니다. 기관의 거절·본인 확인은 보호자에게 넘깁니다. |
| 개발과 산출물 | Codex로 기획 정리·구현·검증을 지원했습니다. 화면은 React 19·Next.js 16 기반입니다. [모델·서비스·자산 사용 내역](THIRD_PARTY.md) · [라이선스 원문](THIRD_PARTY_LICENSES.txt) |

소스 재빌드는 `npm.cmd run build`, 자동 검사는 `npm.cmd test`입니다. 패키징 검사까지 재현하려면 Python 3.10 이상을 함께 설치합니다. 전화 코드의 가상 실행은 `npm.cmd run phone:preview`입니다. 센터의 Windows PC에서는 Node와 브라우저로 구동하며 로컬 GPU 추론은 사용하지 않습니다. 실제 센터 PC 설치·마이크 품질은 현장 미검증입니다. 지역 등록자료 검색과 고정 예약 시연은 첫 설치 뒤 로컬 자료를 사용합니다. 실제 모델, 지도 타일, 항공권 및 병원 공식 창구 검색은 인터넷에 연결됩니다.
