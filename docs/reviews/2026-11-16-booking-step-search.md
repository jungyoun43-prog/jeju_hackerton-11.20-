# 예약 단계 이동·검색 검증 · 2026-11-16

문제는 병원 선택의 자동 전환, 서로 다른 상단/오른쪽 단계, 스크롤 아래의 다음 버튼, 일정 조회 전 접수 질문의 혼재였다. 병원·진료과 → 의료진·시간 → 접수 확인 → 이동·준비표로 통일하고 선택 요약·이전·주황 다음 버튼을 스크롤 밖의 공통 하단에 배치했다. 선택할 것이 남았을 때는 필요한 입력을 하단에 설명한다.

## 반영

- 병원·진료과·제주 지역은 shadcn Popover/Command 검색과 목록 선택. 공개 병원은 이름·등록 주소 검색, 빈 결과 설명, 검색어 지우기, 선택한 기관의 등록 진료과 지정을 지원한다.
- 월별 하루/기간 → 가능한 의료진·시각 선택 → 초진·재진/의뢰서 확인. 하단 행동으로 달력 아래 의료진 목록에 초점을 옮기며 모바일 준비 단계 탭에서도 할 일 화면으로 돌아온다.
- 공개 병원에는 가상 의료진·빈자리를 붙이지 않는다. 희망 이름·시각은 사용자 조건으로 입력·저장하며 기관 소속·진료 가능·예약 미확인을 표시한다. 첫 날짜 선택 후 하단 버튼은 희망 의료진·시간 조건으로 안내한다.
- 뒤로가기, 서류 조회, 답변 수정 화면을 여는 동작은 기존 선택과 확인을 보존한다. 실제 답변·일정 변경 때 관련 이동 확인을 해제한다. 접수 응답 전 요청 차단과 의뢰서 미준비/미확인의 상담 경계를 유지한다.
- 기존 대화 폼은 DOM을 보존한 채 예약 중 hidden/inert로 전환한다. 대화 복귀 시 초안·편집·음성/복구 동작을 유지한다. 안내는 기존 공통 하단에 남긴다.
