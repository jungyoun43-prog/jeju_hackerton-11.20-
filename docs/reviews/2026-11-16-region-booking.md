기존 taskspace 4를 이어 사용했다. 첫 화면의 PC/모바일 캡처와 제주 달력/시간 화면을 직접 확인하고 한 번의 수정 묶음으로 선택 시간 hover 대비, 중복 지역 이동 버튼, 제주에 남아 있던 공항·의뢰서 문구를 고쳤다. 최종 `ego/final-jeju-1440.png`, `ego/final-jeju-390.png`, `ego/final-resume-1440.png`, `ego/final-resume-390.png`를 직접 열어 확인했다. 실제 ego 조작으로 제주 11월18일 09:30, 서울 12월8일 14:40을 선택해 첫 화면의 독립 이어보기 요약을 관측했다. 브라우저에 결과 페이지를 남겼다.

Impeccable의 Operate·distill·craft-floor를 적용했다. detector 1회에서 기존 Pretendard 선언과 디자인 메타데이터 불일치 2건, 색·반경·글자 크기 advisory 69건이 남았다. detector 전체 통과를 주장하지 않으며 부수적인 디자인 메타데이터 복구는 수행하지 않았다. 전체 품질의 자동 합격이나 실기기·스크린리더 검증으로 확대하지 않는다.
