# 혼디 (hondi)

제주에 사는 부모님의 진료를 내륙에서 챙기는 가족을 위한 AI 비서입니다. 집에서 몇 시에 출발할지, 병원에서 누구를 만날지, 어떤 서류를 챙길지 한 일정표에 모아 줍니다.

[공개 앱 열기](https://d1mfksxrj025bx.cloudfront.net/) · [기획서 PDF · 9쪽](docs/submission-proposal.pdf)

## 진료와 이동 준비하기

공개 앱에서 **제주 병원 → 글로 요청**을 고르고 이렇게 적어 보세요.

> 애월에 사는 어머니가 다음 달 오후에 제주우리병원 정형외과에 가고 싶어 하세요. 휠체어 차량이 필요하고 병원에서 동행인을 만나고 싶어요.

혼디가 문장에서 병원과 이동 조건을 찾아 채웁니다. 남은 날짜와 시각을 고른 뒤 **이 내용으로 예약 시연 시작**을 누르면 병원·차량·동행의 가상 회신이 도착합니다. 차가 없으면 다른 출발 시각을 고르세요. 병원과 동행 일정은 **내 예약 현황**에서 함께 확인하고 수정할 수 있습니다.

**내륙 병원**을 고르면 월간 달력에서 희망일이나 기간을 정하고 시연용 시간표에서 의료진과 진료 시간을 고릅니다. 진료의뢰서 준비 여부, 공항까지 가는 길, 숙박 여부도 함께 챙길 수 있습니다. 항공권은 선택한 날짜로 스카이스캐너에서 가격을 비교합니다.

## 제주 데이터에 질문하기

첫 화면에서 **대화·자료 준비 열기**를 누르고 “애월읍에서 전화할 수 있는 택시 업체 한 곳과 자료 기준일을 알려줘”라고 물어보세요. AI가 등록 자료를 조회해 문의처와 그 근거를 알려줍니다.

**제주 병원 → 하나씩 선택**에서는 병원명이나 주소로 검색하고, 목록에서 등록 진료과와 출처를 펼쳐볼 수 있습니다. 목록에는 제주데이터허브 공개 표본 20행 중 수집 당시 정상 등록된 13곳이 들어 있습니다. 지역별 문의처는 콜택시 업체 34곳, 돌봄시설 19곳, 제주시 공공보건 문의처 35곳의 자료에서 찾습니다. [자료 출처와 기준일](docs/data-sources.md)

## 내 컴퓨터에서 실행하기

Node.js 22.9 이상과 npm이 필요합니다. 저장소를 내려받고 `package.json`이 있는 폴더에서 실행하세요.

```sh
npm ci --ignore-scripts
npm run dev
```

브라우저에서 [로컬 앱](http://127.0.0.1:4173/)을 여세요. 예약 시연과 제주 등록 자료 검색은 키 없이 이용할 수 있습니다. 로컬에서 AI 대화나 실시간 음성 대화를 쓰려면 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`를 입력한 뒤 서버를 다시 시작하세요. [AI 설정과 호출 한도](docs/api-usage-contract.md)
