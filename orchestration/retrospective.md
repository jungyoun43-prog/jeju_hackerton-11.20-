## 롤백

롤백 격리 검증: `mvp/rollback-check`의 marker 커밋 `fb9e629`를 `d4d1f84`에서 revert했다. 복원 tree `e1e7e44^{tree}`와 정확히 일치해 통과했다. 검증 worktree는 clean 상태에서 제거했고 브랜치 이력은 로컬에 남겼다. 실제 통합 커밋에 대한 helper는 미리보기·allowlist·clean guard를 확인했으며, 정상 구현에 `--apply`를 실행한 것은 아니다.

- 진행 갱신은 확정 이력의 출처 DOM을 다시 만들지 않는다. SVG 직렬화 문자열과 입력 마크업 비교의 차이도 동일 노드 교체를 유발하므로 실제로 렌더한 문자열을 보관한다. 확정/진행 목록을 나누고 현재 화면의 초점 링크 위치만 잔여 보정해 읽는 위치를 유지한다.
- 포커스가 input에 남는 검사만으로 준비 이력의 읽기 보존을 증명하지 않는다. 이전 요청의 병원 출처 링크를 읽는 다음 요청에서 앞 자료 단계와 같은 병원 단계의 진행을 갱신하고 같은 노드·초점·실제 화면 위치를 함께 검사한다. 절대 scrollY 값은 정상 브라우저 앵커링으로 바뀔 수 있으므로 같은 콘텐츠의 viewport 위치를 관측한다.
- UI 수정 중 실행된 독립 QA의 해시 실패를 최종 통과로 옮기지 않는다. 4192 서버 종료/연결 오류와 390×500 표 키보드 실패를 보존하고, 최종 동결 소스는 별도 소유 TTY4196에서 기존 단언을 유지한 네 브라우저 프로세스가 모두 끝난 뒤 eval한다. 검사 기본 주소를 확인하지 않은 ad-hoc GET4173은 중단했으며 유료 모델 POST는 없었다.


## 2×2 복원에서 반영한 규칙

- 스크롤 방식과 배치는 별개 요구다. 내부 세로 스크롤 제거를 그리드 삭제로 확대 해석한 것은 오류이며, 사용자 정정 후 PC2×2·모바일 네 칸 전체 표시를 복원했다. 최신 계약·AGENTS·PRODUCT·DESIGN·PRD의 같은 오해도 바로잡는다.
- 결과 높이를 자르지 않고 각 칸의 자연 높이와 페이지 스크롤을 사용한다. 검사도 CSS 이름이 아닌 네 칸의 실제 좌표로 PC2열2행/모바일1열4행을 확인한다. 초기 입력을 첫 화면에 억지로 맞추는 이전 단언은 최신 요구에 따라 문서 접근성으로 정정한다.
- UI3파일19추가/26삭제로 범위를 제한하고 기존 의미 색·출처 DOM/focus 보정·전화/기록 경계를 유지했다. API·모델·공공데이터 로직은 바꾸지 않았으므로 이번 공개 검증은 실제 고정 preview와 정적/API revision을 확인하고, 이전9fc11bc 실모델/DDB 증거를 새 버전에서 실행한 것으로 바꾸지 않는다.
- 최종 브라우저4종은 동결 소스에서 직접 node 명령·각각 소유한 TTY로 실행해 모두 종료0과 완성 proof의 동일 지문을 확인했다. 이전 실행의 npm wrapper143 원인은 확정하지 않았으며 이번 실행을 그 원인 규명으로 해석하지 않는다.
