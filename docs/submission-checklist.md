# 대회 제출 요건 추적표

작성·확인 기준일: 2026-10-31 · 사용자 제공 대회 요건과 기존 공식 조사 기록을 연결했다. 최신 공지는 제출 전에 다시 확인한다.

상태는 **설계 반영 / 구현 중 / 검증 대기 / 미완료 / 검증 완료**로 구분한다. 파일이 존재하는 것과 정상 작동·권리 확인·제출 완료는 서로 다른 상태다. 이번 방문 지원·대시보드 확장은 통합 검증 대기이며 이전58/33/19·AWS 배포 결과와 구분한다. 통합 후 실제 증거는 [구현·검증 결과](implementation-results.md)에 기록한다.

## 4. 남은 제출 작업

1. Agent 구현 주장에 맞는 실제 모델·Prompt·Tool 연동과 실행 검증. 현재 결정적 시뮬레이터와 구분한다.
2. 실제 전화 기능을 제출 성과로 주장할 경우 협조받은 테스트 번호의 국내 발신 증거.
3. 이번 방문 지원·대시보드의 통합·브라우저·빌드·ZIP·하네스·독립 검토·AWS 배포 결과 갱신. 이후 모델·통신을 연결한 버전도 재검증.
4. 최종 기획서 PDF 15페이지 이내 확인과 센터 실행·외부 의존성 고지.

전체 운영 API 확장은 선택 사항이다. 현재 연결한 3종 외의 후보는 별도 조사에서 관련성·접근범위·최신성을 비교하고, 데이터 개수를 늘리기 위해 기능에 넣지 않는다.

현 단계의 동작 가능한 MVP는 설계 검증용 산출물이다. 이 체크리스트의 필수 항목이 열려 있는 동안 최종 제출 준비가 완료됐다고 보고하지 않는다.
