# 희망 날짜에서 의료진·이동 예약 창구까지

2026-11-16 사용자 후속 요청. 예약 UI의 의료진 우선 흐름보다 이 계약을 우선한다. 브랜드·대화/복구·실제/시연 경계는 유지한다.

## 날짜 우선

- 병원·진료과와 접수 조건 확인 후 월간 달력을 연다. 의료진을 먼저 고르게 하지 않는다.
- 하루 또는 기간을 고른다. 기간은 시작·종료일을 모두 포함하며 역순으로 눌러도 정렬한다. 월·연도 사이를 이동해도 미완료 기간과 선택한 시간은 보존한다. 세 번째 날짜 클릭은 새 기간을 시작한다.
- 결과는 날짜 순서로, 같은 날짜 안에서는 의료진과 가능한 시간을 보여준다. 마감 시간은 선택 목록에 만들지 않는다. 공개된 빈자리 없음과 미공개 일정을 실제 예약 불가로 동일시하지 않는다.
- 기간 시작일만 골랐을 때는 종료일을 요청한다. 기간 안의 실제 fixture 슬롯만 선택할 수 있고, 날짜/기간 변경은 이전 의료진·시간·요청 상태와 교통 체크를 해제한다.
- 선택 시간은 희망 일정이다. 의뢰서 미준비·초진 여부 미확인은 상담으로 이어지고 합성 확정 회신도 차단한다.
- PC는 달력 옆에서 결과를 비교하고, 모바일은 같은 DOM에서 달력 다음 결과를 읽는다. 기존 공유 스크롤·단일 입력·키보드 초점·44px 조작 영역을 유지한다.

## 교통

- 항공 검색을 긴 체크리스트 앞에 둔다. 희망 진료일을 사용해 당일/전날 출발을 선택하고 날짜를 직접 수정할 수 있다. 귀가 미정은 편도 검색으로 남긴다.
- 항공권은 사용자가 승인한 외부 가격 비교 방식이다. 제주–김포, 날짜·성인 수·일반석 조건만 스카이스캐너에 전달한다. 역순·지난 날짜·다른 공항 조건에서는 잘못된 날짜 링크를 제공하지 않는다. 앱 안에서 실제 운임/발권을 보여주는 기능은 만들지 않는다.
- 일반 택시는 카카오 T 공식 예약/앱 안내와 제주 공개 문의 후보의 전화로 연결한다. 버스 선택 시 노선/운행 안내를 우선한다.
- 휠체어 탑승 차량은 제주와 서울 접수를 분리한다. 제주 당일 즉시콜, 사전 등록·자격과 서울 별도 등록/접수 조건을 표시한다. 공식 접수 페이지를 열어도 혼디의 예약 상태는 변경하지 않는다.
- 체크박스는 20px 표시와 44px 버튼/행을 구분하고, 키보드·행 클릭·초점 표시를 유지한다. 체크는 문의 메모이며 실제 배차/예약 완료가 아니다.
- 모든 새 상태는 현재 탭 메모리다. 모델·DB·환자 기록·저장소 쓰기·자동 외부 요청을 추가하지 않는다.

## Impeccable 적용

`impeccable context --target web/components/appointment-root.jsx`가 이번 실행에서는 성공했다. 기존 PRODUCT/DESIGN과 `distill`, `operate`, `craft-floor` 지침으로 필수 선택 단계 축소, 현재 작업 중심 위계, 반복 표식 제거, 체크박스 정상화, 날짜 결과 비교와 외부 행동 연결을 적용했다. 이전 launcher 실패 기록과 구분한다.

기계 검사 `detect --json`을 변경 대상에 1회 실행했다. 기존/추가 리터럴 색·크기·반경과 Pretendard Variable 선언의 디자인 문서 불일치가 보고되어 전체 detector 통과로 표시하지 않는다. 디자인 sidecar 정리나 스킬 업데이트는 하지 않았다. PC·모바일 관측은 CSS viewport 검증이며 실기기/스크린리더 전면 검증이 아니다.
