# 보호자 관점의 배포 서비스 사용성 평가

2026-10-31. 대상은 변경 전 배포5ae1c4854b79066340635ed4b1fa5d12faea3315다. 실제 인간 참가자 인터뷰가 아니라, 독립 두 검토와 통합 담당자의 실제 배포 브라우저 역할 수행 평가다. 환자·요청은 합성이며 실제 발신·기록 연계·예약을 하지 않았다.

## 방법

- A: 새 방문자/모바일 보호자의 시각·동선 평가. 실제 페이지를 읽고 입력/메뉴/초기화만 조작, POST 없음. B 결과를 보지 않았다.
- B: 독립 탐지기/접근성/반응형 점검. 실제 탐지기는 Permission denied(exit126)여서 발견0건으로 간주하지 않는다. 별도 브라우저 관측을 사용했다.
- 통합 담당자: 공개 AWS 앱의 입력/보내기 버튼을 사용해 자연스러운 보호자 요청5개를 실행했다. 이전 배포 검증의 get_case 도구명 지정 스모크와 다르게 일상어로 요청했다.

## 디자인·인지 평가

A의 초기 공개 화면 휴리스틱 점수는26/40이다. 시스템상태3·현실언어3·사용자통제2·일관성3·오류예방2·인지3·효율2·미학3·오류복구3·도움말2다. 실제 모델 과업의 실패를 반영해 산정한 점수나 변경 후 점수가 아니다.

강점은 자연어 입력이 먼저 있고, 병원·자료·이동·동행 상태를 함께 읽으며, 합성 응답과 예약 미확정을 구분한다는 점이다. 한편 실제 과업에서는 긴 답변의 ###·**가 그대로 출력됐고, 응답 뒤 도구 기록 맨 아래로 이동해 핵심 답을 다시 찾아야 했다. 모바일은 중첩된 짧은 대화 스크롤로 읽기 부담이 컸다.

우선 개선 사항은 다음과 같다.

1. P1: 복합 요청의 마지막 요약 기회를 확보하고 완료한 준비를 보존한다. 단계 제한을 일일 한도 소진과 구분한다.
2. P1: 모바일 입력 가까이에서 가상 체험·실제 연락/예약 없음이 계속 읽히게 한다. 새 대화의 초안/대화 소실을 보호한다.
3. P2: 가상 환자가 방문자의 실제 부모라는 오인을 줄이고 대상자/보호자를 구분한다. 명확한 이미지·글자 위계·현재 작업으로 서비스 맥락을 전달한다.
4. P2: 답변 형식을 안전하게 표시하고 처리 기록은 펼쳐 본다. 새 답변의 시작과 다음 행동부터 읽히게 한다.
5. P2: 음성 인식 후 내용을 수정하고 보내는 제어를 제공한다. 이 변경은 실제 마이크 품질 검증을 대신하지 않는다.

후속 사용자 요청은 왼쪽의 선택적 선호 설정과 이미지, 실제 의료 웹사이트 참고였다. 이에 따른 구현 방향·출처는 ../medical-reference-design.md, 설정 계약은 ../caregiver-preferences-contract.md에 기록한다. 이 평가는 개선 전 결과이며 변경 후에는 별도 과업·브라우저·배포 증거가 필요하다.

## 검사 한계

Impeccable의 context/storage/detector launcher가 실행 권한126으로 실패해 자동 snapshot/trend/overlay를 만들지 않았다. overlay나 새 서버를 시작했다고 주장하지 않는다. 독립 검토의 임시 브라우저와 통합 역할 수행 브라우저는 모두 종료했다. 공개 의료 서비스 비교의 제품 내부 관측과 마케팅 이미지 관측은 후속 참고 보고서에서 구분한다.
