## 롤백

통합 커밋은 `orchestration/state.json`에 기록한다. `npm run rollback -- <SHA>`로 변경 없는 미리보기를 실행한다. 실제 적용은 clean 상태에서 허용된 커밋에만 `git revert`로 수행하며 이력을 지우지 않는다. 성공한 현재 결과를 되돌릴 필요는 없으므로 정상 UI에 대한 실제 revert는 수행하지 않는다. 별도 임시 worktree에서 marker 커밋→revert→원래 tree 일치 검사로 가역성을 확인하고 결과를 아래에 남긴다.

롤백 격리 검증: `mvp/rollback-check`의 marker 커밋 `fb9e629`를 `d4d1f84`에서 revert했다. 복원 tree `e1e7e44^{tree}`와 정확히 일치해 통과했다. 검증 worktree는 clean 상태에서 제거했고 브랜치 이력은 로컬에 남겼다. 실제 통합 커밋에 대한 helper는 미리보기·allowlist·clean guard를 확인했으며, 정상 구현에 `--apply`를 실행한 것은 아니다.
