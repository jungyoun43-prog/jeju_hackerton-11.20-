# MVP 구현·검증 결과 기록

기준일: 2026-10-31 · 현재 범위: 병원·택시·돌봄 공개 자료 + 합성 의료·지원 문의 흐름. 방문 지원 확장과 새 대시보드는 최종 통합 검증 대기다. 이전 버전의 완료 증거는4절에 보존한다.

개발 환경은 Linux·Node v22.23.2·npm 10.9.8, 브라우저 QA는 Playwright 1.64.1·Chromium이다. 실행 소스 지문·검사 수·캡처는 검증한 버전의 `orchestration/runs/` 증거를 따른다. 이전 버전의 통과 결과를 새 UI·데이터 버전의 검증으로 대신하지 않는다.

## 1. 문제와 구조

제주 환자와 기존 도외 주치의 사이의 협진 준비에서 보호자가 기관 문의·필요 서류·추가 요청·회신·동행을 연결해야 하는 문제를 다룬다. 환자 진료 장소를 AI가 결정하는 기능은 구현 범위에 포함하지 않는다.

구조는 **공개 병원·교통·돌봄 자료 → 방문 조건별 후보·질문 → 병원/지원 문의·자료·검토 시뮬레이션 → 조건 변경 재확인·가족 실행 계획**이다. 기관 등록 정보와 문의·의료진 회신은 출처가 다르다. 개발 서브에이전트는 별도 worktree에서 작업하며 서비스의 다중 임상 Agent 구조로 설명하지 않는다.

## 4. 보존한 이전 검증 이력

### 4.1 병원 데이터·일러스트 제거 버전

아래는 이동·동행 확장 이전 실행 소스의 결과다. 문서 정리 버전 `ad6fc2c`의 [Actions41198504055](https://github.com/jungyoun43-prog/jeju_hackerton-11.20-/actions/runs/41198504055)도 성공했으며 새 지원 기능의 검증으로 인용하지 않는다.

통합 검증의 실행 소스 지문은 `3263e0f638a4bdcb033ce35d25bf00895d53ddf7f8ffc6a3a9a762aeeb0307a5`다. 확인한 배포 커밋은 `60ad28fb0ad6a160d73a4690e51b3111746cde49`이며, 이후 문서 정리와 실행 소스의 변경을 구분한다.

- 단위·서버·공공데이터·정적 호스팅·AWS 도구 검사 **58/58** 통과.
- 로컬과 실제 CloudFront 주소에서 브라우저 **33/33** 통과. PC 1440×900·모바일 390×844 첫 행동·이미지 로고·폰트·의사 일러스트 제거·실제 지도 배경을 확인했다.

### 4.2 초기 합성 MVP

공개 후보 연결 이전의 합성 MVP에서 확인한 결과다. 현재 버전의 검사 수나 독립 검토 판정으로 인용하지 않는다.

- 단위·서버·하네스 검사 26개, 브라우저 동선 22개, 자동 규칙 eval 12/12 통과.
- PC·모바일 지도 타일 표시와 타일 전체 차단 시 안내·외부 링크·문의 동작을 확인했다.
- 첫 ZIP을 새 디렉터리에 풀어 설치·검사·빌드·주요 HTTP 5개 응답을 확인했다.
- 임시 worktree에서 marker commit을 revert한 뒤 기준선 tree가 복원되는 것을 확인했다.
- 읽기 전용 검토가 당시 소스·두 캡처·브라우저 기록·소스 지문을 대조했다. 이후 사용자의 디자인 피드백으로 화면을 다시 설계한다.
- AWS 첫 CI 실행 [41196741118](https://github.com/jungyoun43-prog/jeju_hackerton-11.20-/actions/runs/41196741118)은 검사·빌드·artifact 업로드 후 OIDC 인증에서 실패했다. GitHub immutable subject에 맞춘 신뢰 정책을 수정해 CloudFormation `UPDATE_COMPLETE`를 확인했으며, 다음 실제 배포 실행은 별도 확인한다.

## 5. 한계와 센터 활용

- 병원·택시·돌봄의 등록/연락 사실은 실제 출처를 쓰지만 환자·기관 문의 응답·자료 제출·의료진 회신·지원 응답은 결정적 재현이다. 실제 발신·배차·동행인 배정·결제·기관 전송·임상 판단이 아니다.
- 택시2026년 파일과 돌봄2020년 표본의 시점을 구분한다. 일반 돌봄 등록은 병원동행 제공의 근거가 아니며 교통약자 차량은 이용자격·회원등록 확인이 필요하다.
- 런타임 모델과 모델별 Prompt·Tool 호출은 연결하지 않았다.
- 지도 위 가상 위치는 실제 참여 기관·환자 주소가 아니다. 경로 API 없는 이동시간을 만들지 않는다.
- 비용은 사용자 가정이다. 한국 급여 적용·환자별 본인부담·항공·숙박 견적을 검증한 결과가 아니다.
- 최소 PC 사양을 고려한 가벼운 구성과 센터 i7-8700 / GTX 1060 / RAM 32GB 실기기 검증을 구분한다. 센터 실행은 미완료다.
- 최종 기획서 PDF의 15페이지 이내 렌더링·확인은 남아 있다.

센터에서는 출발지역·병원·날짜·지원요건 변화가 후보·질문·재확인 작업에 미치는 영향을 합성 사례로 시연하고, 문의·자료·검토 상태와 누락 담당자를 확인할 수 있는지 평가한다. 실제 환자 운영은 의료진·기관·정보 처리 책임자와 검증 범위를 정한 뒤 진행한다.

미완료 항목은 [제출 추적표](submission-checklist.md)를 따른다. 자동 규칙 준수율을 임상·법적 타당성 또는 최종 제출 준비 점수로 사용하지 않는다.
