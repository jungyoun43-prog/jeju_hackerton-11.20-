# 제출 ZIP 구성

`npm run package`는 `output/jeju-care-compass-mvp.zip`을 생성한다. Node.js22·npm·Python3이 필요하며, 모델 키나 AWS 인증은 패키징에 필요하지 않다.

## 포함하는 자료

- 실행 소스·Prompt·Tool/API·공개 snapshot과 처리 코드: `app/`, `agent/`, `prompts/`, `scripts/`, `tests/`.
- 설치/실행과 제출 설명: README·환경변수 예시·PRD·사용자 매뉴얼·데이터 활용 명세·결과 설명·12페이지 기획서·라이선스/외부 사용 내역.
- 기존 정적 빌드와 배포/개발 설정: `dist/`, `infra/`, `.github/`, `orchestration/`의 소스·규칙, 디자인 명세.
- 검증 요약: 최신 로컬7종·규칙 eval·기획서·배포·ZIP 독립 설치와 현재 모델 미검증 상태. 과거 모델 평가3개는 당시 지문·시점 그대로 포함한다.
- 대표 화면: 선택형 체험의 PC 초기·PC 완료·모바일 완료3장과 실제 API/브라우저 검증 요약이다. `docs/reviews/2026-11-15-evidence/`에 소스·이미지 SHA와 함께 보관한다. 같은 실행의 중간 캡처·실패 시도 전체는 개발 보관본이다.

## 개발 보관본과 구분

반복 촬영한 과거 화면·실패 시도·전체 로그·성능/디자인 검토 원본 디렉터리는 제출 ZIP에 재귀적으로 넣지 않는다. `.env`·인증정보·Git 저장소·설치된 node_modules도 제외한다. 선택한 입력의 심볼릭 링크는 외부 파일을 읽기 전에 거절하며, 거절되면 기존 ZIP을 보존한다.

검증 JSON의 과거 실행 경로·이미지 SHA는 당시 관측을 설명하는 메타데이터다. 해당 원본 전체가 이 ZIP 안에 있다는 뜻은 아니다. 전체 검증 이력과 기존403MB 개발 스냅샷은 개발 환경의 별도 보관본에 남긴다. 전체 이미지/로그가 필요한 감사는 그 보관본으로 수행한다. 이전 결과 문서의 버전별 기록은 재표기하지 않는다.

## 압축 해제 후 확인

```bash
npm ci --ignore-scripts
npm test
npm run build
npm run build:agent
npm run dev
```

키가 없으면 중앙 **방문 준비 시작**에서 네 질문에 답하고 준비표까지 확인할 수 있다. 자유 입력의 실제 모델 응답은 별도 API 키·사용 가능 크레딧이 필요하다. 이 저장소의 ZIP에는 키 원문을 넣지 않는다. 공식 공지의 실제 AI API 평가용 키 제공 조건은 [제출 추적표](submission-checklist.md)의 별도 확인 항목이며, 선택형 체험의 키 없는 실행이 그 조건을 면제한다는 뜻은 아니다.

`npm run eval`은 개발 저장소의 Git·등록 worktree와 전체 검증 원본을 대조하는 개발 전용 검사다. 압축 해제한 제출본은 위 설치·단위·빌드·앱 실행으로 확인한다. 현재 코드와 실행 지문이 같은 과거 UI 검증을 새로 실행한 결과로 표시하지 않는다. 실제 전화·배차·건강기록은 합성 시연 범위다.
