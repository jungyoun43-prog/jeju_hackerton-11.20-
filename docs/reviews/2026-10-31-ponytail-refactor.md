# Ponytail 변경 독립 검토

2026-10-31. 읽기 전용 검토. 기준 `d7cd983`, 검토 HEAD `ed8ccf9`와 당시 문서 작업트리를 비교했다. 통합 담당자가 고정해 전달한 런타임 지문은 `b74ddf4901db7185bb959546bc19abe6cc55bc96e8a5d99c00f5645dd9269a64`이며 이 검토에서 다시 계산하지 않았다.

이 변경은 호출되지 않는 워크스페이스 함수 네 개와 전용 CSS를 제거하고, 진행 DTO 검증·도구 목록을 기존 공통 모듈로 모은다. 취소된 음성 인식의 늦은 이벤트를 차단하고, 제출 ZIP에 넣을 경로의 심볼릭 링크를 ZIP을 열기 전에 거절한다.

**발견사항: 0건. 판정: 반영 가능(Ship).** 검토한 변경과 실제 호출 경로에서 필수 수정 버그·보안 회귀·검사 누락·불필요한 추상화를 발견하지 못했다.

## 확인한 근거

- `app/preparation-stages.js`의 공통 검증은 기존 서버의 고정 키, plain object, 단계 순서, 정규 UTC 시각, 순번 1~128, 순증가 이벤트, 도구 enum, UTF-8 8KiB 제한을 보존한다. `agent/progress.mjs`의 기존 export와 잘못된 DTO에 대한 TypeError 경계를 유지한다. 브라우저 수신과 작업창 projection도 같은 함수를 사용하며, 진행 읽기 실패는 기존 catch 안에서 끝나 원래 응답을 막지 않는다.
- `PROGRESS_TOOLS`는 기존 고정 표시 사전에서 한 번 정의하고 서버에서 재수출한다. 17개 모델 도구와 내부 준비 도구 두 종류를 대조하는 기존 검사를 유지하고, 동일 배열·동결 여부 검사를 더했다. 순번 0은 리포터 내부 초기 상태이며 첫 실제 전이가 1로 증가한 뒤 저장하므로 새 거절 조건이 유효한 서버 진행을 버리지 않는다.
- `app/conversation.js`의 음성 start/result/error/speechend는 현재 인식기인지와 취소 여부를 확인한다. end의 기존 인스턴스 확인과 함께 취소·새 대화·새 음성 시작 이후 이전 이벤트가 초안과 현재 인식 상태를 바꾸는 경로를 막는다. 지연 abort fixture는 늦은 이벤트, 기존/새 초안, 전송 가능 상태, 사용자 확인 후 요청 한 건을 검사한다.
- 삭제한 함수 네 개와 CSS 선택자는 현재 소스·검사에 참조가 없다. `workspace.html`의 진입점, 실제 view 선택·렌더, 지도·수동 작업·공유 스타일은 유지된다. 삭제량은 함수 16줄과 CSS 195줄, 총 211줄이다.
- `scripts/package.mjs`는 선택 경로와 root 아래 조상을 존재 확인 전에 검사하고, 모든 중첩 링크를 일반 파일 검사 전에 거절한다. 검사한 항목을 모은 뒤 ZIP을 열어 링크 발견 시 기존 ZIP을 보존한다. 기존 제외 항목·허용 evidence 목록은 보존된다. 실제 패키지 명령 fixture는 일반 파일·빌드·라이선스 포함, .env 제외, 중첩 파일/디렉터리·선택 디렉터리·선택 경로 조상 링크 거절과 기존 ZIP 보존을 검사한다.
- 새 프레임워크·의존성·범용 wrapper·설정은 추가하지 않았다. 서버 wrapper는 기존 호출부와 오류 API를 보존하기 위한 최소 코드다. writer 소유권·TTL·I/O 예산·세션 lease·일별 budget, 의료·동의·실발신 경계를 변경하는 diff는 없다.

## 검토 범위와 한계

`AGENTS.md`, `README.md`, Ponytail 기본·review 스킬, 리팩토링·작업창·파일 소유권 계약을 읽었다. 변경 파일 전부와 연결된 `agent/service.mjs`, 메모리/DynamoDB 진행 저장·조회, `scripts/build.mjs`, `orchestration/checks.mjs`, 워크스페이스 진입·렌더, 브라우저/단위 회귀 fixture를 확인했다. 부하는 문서의 로컬 시연 및 AWS 동시 실행 2·UTC 하루 80요청 범위를 가정했다.

이 검토는 소스·검사 코드를 읽었으며 테스트·브라우저·모델·AWS·네트워크 명령을 실행하지 않았고 .env를 읽지 않았다. 통합 담당자의 전체 검사 결과를 독립 실행 결과로 주장하지 않는다. 전달받은 네 작업창 모바일 키보드 검사 1건의 불안정성은 실행으로 판정하지 않았으며 통합 검증에 남아 있다.

건너뛴 범위: 실제 마이크 서비스, 배포 결과, 유료 모델, 실제 기관·환자 연계, 임상·법률·데이터 권리 검증. 이번 소스 검토 통과가 이 범위의 완료를 뜻하지 않는다.
