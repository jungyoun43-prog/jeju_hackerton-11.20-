# 서버 API 연결과 호출 한도 · 2026-11-17

사용자가 지정한 로컬 키 파일에서 키 1개를 읽어 프로젝트 `.env`에만 반영했다. 원본 파일은 수정하지 않았다. 키·앞부분·해시를 출력하지 않고 `.env`와 `.runtime/`는 Git에서 제외한다. 브라우저·빌드·공개 응답에 키를 넣지 않는다.

## 현재 설정

서버에서 `gpt-6.1-sol`, `OPENAI_REASONING_EFFORT=medium`을 사용한다. 화면과 공개 capabilities에는 모델명·추론 강도를 보내지 않는다. 대회 제출 문서와 서버 설정은 사용 기술을 기록하는 내부 근거이므로 제품 화면과 구분한다.

| 항목 | 현재 값 | 집행 위치 |
| --- | --- | --- |
| 실제 Responses 전송 시도 | UTC 하루 60회 | 전송 직전 서버 선차감 |
| 한 대화 요청의 모델 호출 | 최대 6회 | 마지막은 도구 없는 요약 |
| 한 호출의 출력 토큰 | 최대 4,096 | Responses 요청 설정 |
| 대화 요청 | 하루 20턴 | 기존 세션 저장소 |
| 호출 대기 | 호출당 40초·요청 전체 45초 | 서버 timeout |

일일 한도는 한국 시각 오전 9시 경계다. 성공뿐 아니라 실패·응답 유실·중단된 전송 시도도 차감하고 자동 재시도·자동 모델 대체는 하지 않는다. 호출·토큰 제한이며 금액의 고정 상한은 아니다.

로컬은 `.runtime/openai-usage/YYYY-MM-DD/NNN.call`의 빈 번호 파일을 `O_EXCL`로 선점한다. 같은 디렉터리를 사용하는 프로세스와 재시작 간 실제 호출 예산을 공유하며 키·환자·입력·응답은 저장하지 않는다. 카운터를 지우거나 다른 디렉터리로 실행하면 독립 예산이 되므로 운영 중 경로를 바꾸지 않는다. 대화 상태·턴 한도는 기존 로컬 메모리 계약을 유지한다.

AWS 경로는 기존 DynamoDB 테이블의 `model-budget#YYYY-MM-DD` 키로 실제 호출 수를 원자 차감한다. 턴 예산과 구분하고 `maxAttempts:1`을 유지한다. 한도 저장 실패·거절·이미 중단된 요청은 외부 모델 전송 전에 멈춘다. 진행 조회·resume·고정 preview·화면 탐색은 실제 호출 예산을 쓰지 않는다. 이번 작업에서는 AWS 비밀값 업로드나 배포를 하지 않았다.

## 실연결 관측

**충전 후 최신 확인:** 사용자의 크레딧 충전 안내 뒤, 같은 서버 설정의 최소 Responses 요청 1건을 HTTP200·4,628ms·completed로 확인했다. 입력20·출력8, 총28토큰을 사용했다. 아래의 429는 충전 전 이력이다. 성공 1건은 범용 모델 품질·실제 제주 운영 API·예약 연동 검증과 구분한다. Realtime 모델 목록 접근도 HTTP200으로 확인했으며 실제 음성 시연과 종료 결과는 [별도 검증 기록](reviews/2026-11-17-compact-entry-voice.md)에 남긴다.

실시간 음성은 별도 `OPENAI_REALTIME_DAILY_SESSION_LIMIT=3`, 서버 180초 만료, 동시1개, 응답768토큰으로 제한한다. 생성 시도 카운터는 `.runtime/realtime-usage`에 남기며 기존 Responses 카운터와 독립이다. 키는 서버에서만 사용하고 화면에 임시 연결 SDP·종료용 토큰만 보낸다. 상세 범위는 [음성 계약](compact-entry-voice-contract.md)을 따른다.

2026-11-17 Ego Lite에서 공개자료 이동 문의를 1회 제출하고, 별도 최소 요청으로 계정 상태를 1회 확인했다. 최소 요청은 HTTP429, 고정 오류 코드 `credit_balance_exhausted`, 유형 `insufficient_quota`를 반환했다. 두 번 모두 응답 생성 성공을 확인하지 못했고 추가 실호출을 중단했다. 계정 잔액을 확인·충전해야 실제 생성 검증을 이어갈 수 있다. 계정 접근 성공·현재 모델 품질·실시간 제주 API 연결을 확인한 것으로 표현하지 않는다.

계정 잔액 오류는 일일 앱 한도·일시적인 요청량 제한과 구분한다. provider는 해당 오류 후 같은 인스턴스의 추가 호출을 멈추고, UI는 운영자 확인 필요와 입력 보존·수동 준비 기능을 안내한다. 잔액 상태는 애플리케이션에서 임의로 변경하지 않는다. 계정 잔액을 보완한 뒤 서버를 다시 시작하고 최소 요청으로 실제 생성·도구 사용을 재검증해야 한다.

회귀 검사는 키 없는 별도 서버와 고정 응답을 사용했다. 실제 키로 전체 브라우저/모델 평가를 반복 실행하지 않는다.
