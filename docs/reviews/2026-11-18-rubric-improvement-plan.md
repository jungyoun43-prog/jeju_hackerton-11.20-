## 보호자 과제와 증거

- **내륙 진료.** Ego Lite에서 서울 한빛대학교병원 종양내과의 12월 8일을 고르고 김도윤 10:30과 14:40을 비교했다. 14:40을 선택하고 ‘준비 단계’와 ‘할 일’을 왕복한 뒤 요청 확인에 같은 의사와 시각이 남았다. 1093×512 CSS 픽셀에서 수정 전에는 883px의 작업면 중 643px만 본문과 하단 버튼이 차지했다. 수정 후에는 모두 883px이었다. 1366×768에서는 실제 단계 목록을 오른쪽에 유지했다. ## 재현

Windows 디렉터리 접합점과 네이티브 키 업로드 어댑터는 별도 검사에서 검증했다. 실제 비밀값 업로드·AWS 변경·기관 발신은 실행하지 않았다. 최종 빌드 지문은 `a513a34a3835e7ff`로 시작한다. [전체 로그](../../output/vehicle-recovery-qa/unit-tests.log)
