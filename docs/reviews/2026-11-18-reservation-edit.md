# 예약 현황에서 조건 수정과 재조율

확인일: 2026-11-18. 로컬 Next.js 정적 UI와 Node 서버를 수정했다. 공개 배포와 실제 전화 어댑터는 변경하지 않았다.

## 사용자 동선

- 예약 현황, 조율 결과창, 조율 완료 화면의 **예약 수정**에서 기존 조건을 불러온다.
- 병원·진료과 / 날짜·의료진 / 이동·동행을 오가며 고친다. 기존 검색·월간 달력·시간 선택을 재사용한다.
- **변경 내용 확인**에서 전후를 비교한다. **변경 적용·다시 조율**로 필요한 시연만 다시 진행하고 결과창과 예약 현황에서 새 결과를 확인한다.
- 적용 전 초안은 기존 결과와 분리한다. 취소하거나 현황으로 나가면 원래 조건과 회신이 남는다. 차량 시각만 변경하면 병원·동행 회신은 보존하고, 진료 일정 변경은 연결된 지원을 재조율한다. 지원을 제외해 남은 결과가 모두 유효하면 추가 실행 없이 현황으로 돌아간다.
- 날짜나 유효한 차량 출발 시각이 없으면 적용할 수 없다. 원래 요청하지 않은 지원은 변경 목록에 표시하지 않는다.

Impeccable의 harden·craft-floor 기준을 사용했다. PC·모바일 첫 확인에서 작은 화면의 제목·탭이 비교 내용을 밀어내는 문제를 발견했다. 한 번의 보완으로 확인 단계 탭과 중복 탐색을 숨기고 변경 전후를 먼저 배치했다. 기존 색·서체·전환은 유지하며 새 UI 의존성을 추가하지 않았다.

- `npm run build`: 통과. `node --check app/conversation.js`: 통과.
- `node --test tests/reservation-edit.test.mjs tests/reservation-overview.test.mjs tests/care-coordination.test.mjs`: **28/28** 통과. 수정 초안의 비파괴성, 되돌리기, 관련 회신 보존, 제외·휠체어 조건, 잘못된 시각, 내륙 의료진·시간의 초기값을 확인했다.
- `scripts/reservation-edit-browser-check.mjs`: **62/62**, 브라우저 예외 0, POST 0. 키 없는 4189 서버에서 외부 요청과 POST를 차단하고 제주 공개 병원 기반 시연을 검사했다. 1280×720, 390×844, 320×600에서 결과창 진입, 병원 검색, 취소·화면 이탈 시 복원, 차량 단독 변경, 진료 시간과 세 예약의 재조율, 하단 버튼 위치와 변경 전후의 화면 내 표시를 확인했다.
- Ego Lite의 실제 PC 창(CSS 2038×1043, 브라우저 배율 125%)에서 제주 요청 → 완료 → 예약 수정 → 차량 13:00에서 12:20으로 변경 → 비교 → 적용 → 완료 → 예약 현황을 사용했다. 병원 14:00, 동행 13:30은 유지하고 차량만 12:20으로 표시되는 결과 3건을 확인했다. 해당 현황 화면을 열어 두었다.
- Ego의 native time `fill()`은 DOM 값만 변경하고 React 입력 반영이 없었던 첫 관측이 있었다. 실제 키보드 ArrowUp/ArrowDown 입력 후 변경이 반영됐다. Playwright의 native time 입력·취소·적용은 세 크기 모두 통과했다. 앱 상태를 직접 주입하지 않았다.

최종 캡처와 보고서: `output/reservation-edit-qa/`의 `report.json`, `date-editor-*.png`, `support-editor-*.png`, `review-*.png`, `edited-overview-*.png`, `ego-review-final.png`, `ego-overview-final.png`.

검증용 Playwright 기본 브라우저 경로가 설치본과 달라 실행되지 않은 첫 시도는 검사 결과에 포함하지 않았다. 설치된 Chromium 실행 경로를 지정해 위 최종 검사를 수행했다. 모바일은 브라우저 viewport 검사이며 실제 휴대폰 검증은 아니다. 내륙 수정은 상태 단위 검사와 공유 편집 컴포넌트 범위이며 실제 브라우저 전체 왕복을 별도로 검증하지 않았다. 여러 항목의 긴 비교는 본문 스크롤을 허용한다.

실제 기관 예약 변경·취소, 실발신·배차·결제·유료 모델 호출은 수행하지 않았다. 결과는 탭 메모리의 가상 회신이고 새로고침 시 초기화된다. 기존 키·권한·모델 설정은 변경하지 않았다.
