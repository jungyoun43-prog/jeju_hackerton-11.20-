# 대회 제출 요건 추적표

작성·확인 기준일: 2026-10-31 · 사용자 제공 대회 요건과 기존 공식 조사 기록을 연결했다. 최신 공지는 제출 전에 다시 확인한다.

상태는 **설계 반영 / 구현 중 / 검증 대기 / 미완료 / 검증 완료**로 구분한다. 파일이 존재하는 것과 정상 작동·권리 확인·제출 완료는 서로 다른 상태다. 통합 후 실제 증거는 [구현·검증 결과](implementation-results.md)에 기록한다.

## 4. 현재 제출 차단 항목

1. 실제 공개 기관 데이터의 조회·선택·문의·보고서 결과를 최종 UI·ZIP의 같은 버전으로 재검증. 공개 표본 20행 분석·13개 후보와 재취득 코드는 구현했다.
2. Agent 구현 주장에 맞는 실제 모델·Prompt·Tool 연동과 실행 검증. 현재 결정적 시뮬레이터와 구분.
3. 실제 전화 기능을 제출 성과로 주장할 경우 협조받은 테스트 번호의 국내 발신 증거.
4. 현재 실제 기관 데이터와 새 UI의 통합·브라우저·빌드·ZIP·하네스 검증 및 AWS 자동 배포 증거 갱신. 이후 모델·통신 연결은 해당 버전을 다시 검증.
5. 최종 기획서 PDF 15페이지 이내 확인과 센터 실행·외부 의존성 고지.

현 단계의 동작 가능한 MVP는 설계 검증용 산출물이다. 이 체크리스트의 필수 항목이 열려 있는 동안 최종 제출 준비가 완료됐다고 보고하지 않는다.
