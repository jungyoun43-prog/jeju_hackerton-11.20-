# 제주 진료 나침반 데이터와 출처 명세

확인일: 2026-10-31 · 연결 문서: [PRD](prd.md)

이 명세는 기획에 사용할 수 있다고 확인한 정보와 추가 확보가 필요한 자료를 구분한다. 공개 화면·메타데이터·미리보기 확인은 전체 원자료 취득, API 호출 성공, 재배포 권한 확인과 다르다. 아래의 ‘미검증’은 구현 전 확인할 의존성을 뜻한다.

페이지 설명은 좌표 변환 문제로 좌표를 제외했다고 안내한다. 미리보기의 데이터 수집일과 행별 갱신일도 구별한다. `openStatus`의 ‘영업/정상’은 지금 진료 중이거나 예약할 수 있다는 뜻이 아니다. 전화번호, 현재 진료시간, 예약 가능일, 검사별 시행 여부, 빈 병상, 개별 환자 적합성은 이 자료에서 확인한 항목이 아니다.

지정 목록은 브라우저 렌더링과 공개 목록 응답의 `start=110`, `pageNumber=12`, `length=10`으로 페이지 번호임을 확인했다. 보건·복지 목록 메타데이터에서 ID 859 등록도 대조했다. `/12`를 의료 분야만의 별도 데이터 집합으로 해석하지 않는다.

### 수집·전처리·분석 계획

1. 등록을 확인한 상세 자료의 이용조건, 프로젝트 키 발급·운영 API 접근을 확인한다.
2. 허용된 방식으로 원자료를 수집하고 출처·조회시점·행별 갱신일·버전을 기록한다. 재배포가 제한되면 제출물에는 취득 절차·허용된 예시만 제공한다.
3. 기관명·주소의 공백과 표기를 정규화한다. 기관명만으로 병합하지 않고 주소와 가능한 식별정보를 대조한다.
4. 진료과목 문자열을 분리하되 원문을 보존한다. 결측과 표기 불일치를 기록한다.
5. 행정 상태·지역·진료과목으로 후보를 조회하고 검색·제외 이유를 남긴다. 오래된 상태나 결측으로 환자 진료 불가를 확정하지 않는다.
6. 공식 기관 연락처와 진료 안내를 별도로 대조한다. 확인한 번호만 문의 대상으로 사용한다.
7. 후보 결과를 요건별 문의와 보고서에 연결한다. 진료과·행정 상태를 바꾸는 대조 검증으로 필수 데이터의 실질적 사용을 확인한다.

분석 단위는 의료기관과 협진 요청의 운영 요건이다. 기관 데이터와 환자 기록을 기관명만으로 결합하거나, 병상 수와 비용으로 환자 중증도를 추정하지 않는다. 초기 구현은 허브 스키마에 맞춘 어댑터와 합성 fixture를 개발하며, 이 검사만으로 필수 데이터의 실제 사용을 입증하지 않는다. 운영 접근·이용조건·실질 활용 증거는 제출 전 열린 필수 항목이다.

## 2. 환자 기록과 의학적 근거

현재 시연은 **암 치료 후 추적 진료를 준비하는 합성 사례**를 예시로 삼는다. 구체 암종·병기·치료 단계와 실제 협력 의료진은 아직 정하지 않았다. 과거 정형외과 수술 후 외래 초안은 현재 확정 대표 사례가 아니다. 치료 이력·판독문·현지 대면 진찰 소견·의뢰서·의료진 회신의 출처를 따로 보존하며, 새 진찰이나 검사 기록을 Agent가 작성하지 않는다. 제주 공공데이터가 개인 환자의 임상 기록을 제공한다고 가정하지 않는다.

초기 문서는 모두 합성임을 내용·화면·보고서에 표시한다. 문헌은 용어 이해와 의료진에게 확인할 질문의 준비 자료다. 암종과 치료 단계가 정해지기 전에 암종별 추적 간격·검사·도외 방문 조건을 일반 규칙으로 만들지 않는다. 임상 근거 선정과 환자별 적용은 협력 의료진 검토 대상으로 남긴다.

아래 4종은 2026-10-31 insane-search로 본문을 확인했다. 국내 병원의 환자 안내, 해외 학회의 환자 교육 자료, 임상 가이드라인, 연구 논문을 구분하며 동일한 근거 수준으로 취급하지 않는다.

문헌별 관리 항목은 원문 URL·DOI/PMID 등 식별자, 발행·개정일, 문서 유형, 대상군, 적용·제외 조건, 인용 위치, 활용·재배포 조건이다. 검색 결과 요약이나 초록만 확인한 경우 원문을 읽은 것으로 표시하지 않는다. 전문을 제출할 권한이 없으면 링크·서지·허용 범위의 인용만 사용한다.

계산에 사용할 때에는 항목 식별자, 적용일, 기관 유형, 환자 자격, 근거 문서와 견적의 포함 항목을 확인한다. 확정할 수 없는 자격·금액은 미확인으로 남긴다. 급여 기준은 비용 적용의 근거이며 환자 상태 평가의 근거로 대체하지 않는다.

insane-search로 위 문서의 본문·표를 확인했다. 서비스 계정 생성, 유료 계약, 실제 발신은 수행하지 않았다. 한국어 음성 지원을 국내 전화망 발신 성공으로 해석하지 않는다. Retell은 검토 후보이며 확정 의존성이 아니다.

병원 답변은 기관·질문·답변 부서/역할·시점·조건을 단위로 기록한다. 공개 진료과 정보, 접수 창구의 안내, 의료진의 환자별 검토, 예약 확정의 근거를 구분한다. 답변은 문의 당시 정보이며, 미래의 검사·예약·치료 가능성을 보장하지 않는다.

## 5. 이동·숙박·동행

초기에는 출처가 있는 견적과 사용자 입력으로 비용·시간을 계산한다. 항공·숙박·택시·경로·동행 서비스 예약 API의 연동은 확인하지 않았다.

여행 견적에는 조회일·이용일·왕복/편도·인원·수하물·세금 등 포함 범위를 기록한다. 가족 각자의 출발지와 동행 가능일을 따로 받는다. 같은 차량·객실을 공유하는 비용을 인원별로 중복 합산하지 않는다.

동행 서비스는 비용과 서비스 제공 지역·시간·이용 가능 여부를 따로 확인한다. 공개 서비스 소개나 예산 입력은 해당 방문의 동행 예약 확정을 뜻하지 않는다.

## 6. 규제 검토 자료

- [의료법 제27조](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020977077): 확인한 현행 표기는 시행 2026-10-02. 비의료인의 의료행위 금지 조항을 확인했다. 이 조문만으로 기획 기능의 적법 여부를 확정하지 않는다.
- [식약처 AI 디지털의료기기 허가·심사 가이드라인](https://mfds.go.kr/law/board/boardDetail.do?brdId=data0011&menuKey=29&seq=15657): 2025-05-07 개정 안내와 첨부 PDF의 판단·허가심사 설명을 확인했다. 실제 제품의 해당 여부 판정을 받은 것은 아니다.
- [복지부 비의료 건강관리서비스 개정 안내](https://eiec.kdi.re.kr/policy/materialView.do?num=229658): KDI가 제공하는 2022-09-01 복지부 발표 자료. 의료인의 진단·처방·의뢰 범위의 보조 서비스와 기관 안내 기준 관련 개정 취지를 확인했다.

실제 서비스의 입력·출력·사용 주체·의도된 용도에 따른 의료행위·디지털의료기기 검토, 민감정보의 처리·공유·외부 전송·보관과 실제 통화 운영 조건은 별도 검토한다. 의료진 검토·참고용 표시만으로 규제가 면제된다고 전제하지 않는다.

## 8. 대회 요건과 재현 기록

[공식 대회 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)와 [공개 응답](https://daker.ai/api/hackathons/jeju-ai-bigdata-agent-challenge)을 확인했다. 필수 데이터 1종 이상 실질 활용, 15페이지 이내 기획서, 코드·실행환경·데이터 명세·결과 설명 ZIP, 센터 최소 사양과 마감을 PRD에 반영했다. 규정과 이용조건은 제출 전에 다시 확인한다.

원자료·전처리·근거 문헌·급여 규칙·견적·프롬프트·모델·코드·보고서 입력의 버전을 남긴다. 제출 가능한 자료의 범위와 재취득 절차를 명시하고 인증정보를 제거한다. 합성 환자·테스트 통화·가정 견적·실제 공공데이터를 구별한다.

insane-search의 `weak_ok`는 본문 검토의 출발점으로 취급했다. 제주 화면은 브라우저 렌더링으로 공개 텍스트·응답을 보완했고, 새 비용 설명·음성 문서는 insane-search 본문에서 확인했다. 실제 원자료·API·통신 연동·개별 환자의 임상 적용은 위 각 항목의 확인 상태를 따른다.
