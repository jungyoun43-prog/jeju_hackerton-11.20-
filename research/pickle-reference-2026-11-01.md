# 피클 공개 안내에서 참고한 대행 흐름

확인일: 2026-11-01. 혼디의 방문 준비 신뢰성 구현에 참고할 공개 제품 설명을 확인했다. 피클을 실제 이용하거나 통화·예약을 성공시킨 검증이 아니며, 피클의 API·소스와 혼디의 독립 설계를 구분한다.

## 확인한 공개 동작

| 공식 출처 | 공개 안내에서 확인한 범위 | 혼디에 적용할 원칙 |
| --- | --- | --- |
| [업무 맡기기 도움말](https://www.pickle.com/help/tasks/delegate) | 대화로 요청하고 필요한 정보만 보완한다. 실행 내용·조건을 카드에서 확인하며 맡긴 일은 채팅의 업무 카드로 이어진다. 앱을 닫은 뒤의 처리, 완료 결과와 예약 증빙 안내를 설명한다. | 같은 요청과 업무 상태를 연결하고, 응답 유실·화면 종료를 실제 업무 실패나 취소와 혼동하지 않는다. |
| [한국 이용약관 제4조](https://pickle.com/ko/terms-of-service) · 시행2026-10-24 | 중요한 단계 전 확인, 결과·실패·미확인의 보고, 회사 번호 발신과 AI/전사 고지, 이용자만 가능한 단계의 인계, 중단과 이미 끝난 행위의 구분을 설명한다. | 허용 범위·실행 상태·확인된 결과를 나누고 본인확인/거절은 사람에게 넘긴다. 실제 수행한 고지·위임·통화만 완료로 기록한다. |
| [예약 작업 도움말](https://www.pickle.com/help/tasks/scheduled) | 예약된 일의 정지·수정·삭제·실행 이력을 제공하고 정지/삭제한 일을 임의로 다시 실행하지 않는다고 안내한다. | 재시도 횟수·기간·철회와 실패 이력을 보존한다. 예약된 행동과 화면의 기다림 중지는 별개다. |

이 원칙은 공개 기능 설명의 비교다. 피클의 화면·문구·프롬프트·비공개 구현을 복사하지 않았다. 혼디는 현재 전화 계정이 없으며 합성 문의·인계만 지원한다. 피클이 통화를 전사한다고 안내한다는 사실을 혼디의 녹음·전사·위임 완료로 옮기지 않는다.

## 공개 코드와 API의 범위

[공식 GitHub 조직](https://github.com/pickle-com)의 공개 저장소를 REST API로 직접 확인했다. 당시 공개 목록은 다음 두 개다.

- [credential-enclave](https://github.com/pickle-com/credential-enclave): Apache-2.0. 위임된 계정 키·OAuth/저장 값·사용 이력과 검증을 다루는 보안 컴포넌트다. README는 앱 바이너리 전체가 아직 공개된 상태가 아니라는 한계도 적고 있다.
- [tau2-bench](https://github.com/pickle-com/tau2-bench): MIT의 도구·사용자 상호작용 벤치마크 포크다.

credential-enclave README의 확인 판본은 [`5066629`](https://github.com/pickle-com/credential-enclave/blob/50666297f3cb0163720fcd9ed3c00cbaf508f987/README.md)이다. 보안 컴포넌트의 실행 전 기록 원칙은 참고하되 Nitro Enclave·외부 계정 금고를 혼디에 도입한 것은 아니다.

확인한 공개 안내에서 외부 개발자가 피클의 전화·예약 엔진을 호출하는 개발자용 API 계약은 찾지 못했다. 보안 컴포넌트의 공개 프로토콜을 전화 API로 해석하거나 엔드포인트를 만들어 연결하지 않는다. 이번 혼디 구현에 이 저장소의 코드나 의존성을 가져오지 않았다.

## 접근 방법과 한계

insane-search를 먼저 실행했으나 `curl_cffi` 미설치·시스템 Chrome 부재로 본문 수집이 완료되지 않았다. Playwright MCP도 현재 도구에 없었다. 도구를 설치·수정하는 대신 기존 Playwright/Chromium으로 공개 페이지를 읽고 공식 검색의 본문과 대조했다.

- 한국 약관은 현재 공개 브라우저 DOM에서 본문과 시행일을 확인했다.
- 업무/예약 도움말은 공식 검색의 본문을 확인했다. 업무 도움말의 직접 브라우저 접근은200이었지만 본문이 비어 있었고, 홈페이지의 networkidle 대기는 시간 초과였다. 이를 로그인 앱 내부 이용이나 정상 UI 동작 검증으로 확대하지 않는다.
- 공식 GitHub 목록·라이선스와 credential-enclave README는 GitHub REST 응답으로 확인했다. 검색에 남아 있는 이전 glass/privacy 저장소 설명을 현재 공개 목록으로 사용하지 않았다.

실제 계약·민감정보 처리·발신 정책에 관한 혼디의 운영 검토는 별도다. 이 조사로 혼디의 적법성이나 피클의 성능을 보증하지 않는다.
