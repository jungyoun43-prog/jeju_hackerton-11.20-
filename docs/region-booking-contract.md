# 지역을 먼저 고르는 진료 준비

2026-11-16 사용자 요구. 첫 진입의 순서는 이 문서가 기존 제주 체험/서울 버튼 안내보다 우선한다.

같은 날 추가된 [제주 데이터 연결 계약](jeju-data-booking-contract.md)이 제주 내부의 가상 병원 기본 진입보다 우선한다. 제주 기본은 공개 병원·희망 일정·문의처 선택이며, 아래 가상 의료진·시간표는 별도 체험 모드로 보존한다. 서울 및 좌우 진입·지역별 이어보기 규칙은 유지한다.

표시 명칭 보완: 화면의 지역 선택·이어보기·단계 제목·저장표는 **내륙**으로 통일한다. 현재 가상 병원 2곳과 항공 검색은 서울·김포 기준이므로 실제 기관명·공항명·서울 이동지원 서비스명은 유지한다. 내부 지역 키 `seoul`과 선택 상태 구조도 보존하며, 명칭 변경을 다른 내륙 도시의 예약·교통 연동 추가로 해석하지 않는다.

명칭 변경 검증(2026-11-16): production build와 기존 지역 브라우저 검사 95/95 통과, 오류·POST 0. Ego Lite에서 내륙 진입·단계 제목·이어보기를 확인했다. 지문 `34f82c44cbb47cdf18311a66b945aecbb3401f20e973ecd2b00b694f6e8a07b6`, 증거 `output/mainland-label-qa/ego-result.json` 및 `output/region-booking-qa/report.json`. 앞선 전체 데이터/대화 회귀를 이 명칭 버전에서 모두 재실행한 것은 아니다.

## 시작과 이어보기

- 첫 화면은 **제주 병원 / 내륙 병원**을 크게 좌우 배치한 두 선택 컴포넌트다. 모바일에서도 두 지역을 나란히 비교한다. 각 전체 영역이 키보드로 선택 가능한 버튼이다.
- 지역 선택 전에는 기존 준비 단계·입력창을 숨기고 비활성화한다. 같은 원본 DOM·입력 초안·출처·단계 상태는 보존한다. 대화·자료 준비는 별도 보조 버튼으로 연다.
- 각 지역에 진입하면 병원·진료과 → 방문 유형/접수 조건 → 월간 달력의 하루·기간 → 의료진·시간 → 요청·회신 체험 → 이동 준비 순서다.
- 제주와 서울의 병원·진료과·희망 날짜·시간·서류 응답·회신·이동 체크는 독립적인 메모리 상태다. `병원 지역 선택`으로 돌아오면 선택한 병원/시간과 `제주/내륙 예약 준비 이어보기`를 표시한다. 새로고침 또는 새 대화는 임시 상태를 초기화한다.
- 접수 화면을 열어 읽는 것만으로 일정을 지우지 않는다. 병원·진료과·접수 응답·날짜·시간 등 실제 조건 변경은 관련 요청·이동 체크를 해제하고 재확인을 표시한다.

## 제주와 서울의 차이

- 제주: 가상 병원 2곳(제주 바람종합병원, 서귀포 온유병원), 기본 가정의학과, 27개 과. 진료의뢰서 답변을 날짜 탐색의 필수 전제조건으로 두지 않는다. 서류 상태는 선택 입력이며 접수/필요 서류는 선택한 기관에 확인한다. 의뢰서가 불필요하거나 급여 요건을 충족했다고 판단하지 않는다.
- 서울: 기존 가상 대학병원 2곳, 기본 종양내과, 27개 과. 초진·재진과 의뢰서 답변을 받고 미준비·미확인 상태는 예약 상담으로 연결한다. 판독문을 진료의뢰서로 대체하지 않는다.
- 4곳 전체의 의료진 110명과 2026년 11월~2027년 1월 슬롯은 가상 fixture다. 실제 병원·의료진의 대기기간이나 실시간 빈자리·예약을 의미하지 않는다.
- 제주 이동은 집→제주 병원→집의 두 구간이며 제주 버스·택시·교통약자 공식 접수를 연결한다. 항공편·공항 입력·서울 이동 체크를 받지 않는다. 입력 시각의 순서만 대조한다.
- 서울 이동은 기존 제주공항→항공편→서울 병원→귀가 흐름과 날짜 기반 가격 비교 링크를 유지한다.
- 제주 결과에서 서울 준비로 이동할 수 있다. 이는 사용자의 지역 선택이며 의학적 의뢰·전원 판단이나 의뢰서 발급이 아니다. 두 지역 선택을 서로 덮어쓰지 않는다.

## 구현·범위

`web/components/care-region-start.jsx`의 React/shadcn Button과 기존 예약 React 루트를 연결한다. `app/conversation.js`는 지역별 임시 상태·표시·초점 전환을 담당한다. 공통 슬롯/의뢰서 검증은 `appointment-demo.js`, 지역별 이동은 `appointment-travel.js`를 사용한다.

LLM·외부 예약 API·DB·전화 발신·로그인·결제를 추가 호출하지 않는다. 의료진/시간 선택과 회신 시연은 기존 원본 환자 상태를 바꾸지 않는다. 외부 링크 정책과 확인 출처는 [교통 연결 조사](../research/booking-handoffs-2026-11-16.md)를 유지한다.

기존 대화/선택형 제주 체험 회귀 검사는 첫 진입에서 `대화·자료 준비 열기`를 선택한 뒤 같은 원래 흐름을 검사한다. 별도 지역 브라우저 검사는 초기 좌우 선택·두 제주 병원·월간 날짜/의료진·지역 전환/이어보기·지역별 이동/저장·초안 보존·무전송을 확인한다.
