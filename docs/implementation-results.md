# MVP 구현·검증 결과 기록

작성일: 2026-10-31 · 상태: 병렬 구현 중, 통합 결과 입력 전

이 문서는 설계와 실행 증거를 구분한다. 아래의 대기는 실패나 통과를 뜻하지 않는다. 통합 담당자가 실제 명령·시각·버전·결과·증거 경로를 확인한 뒤 갱신한다.

## 1. 문제와 구조

제주 환자와 기존 도외 주치의 사이의 협진 준비에서 보호자가 기관 문의·필요 서류·추가 요청·회신·동행을 연결해야 하는 문제를 다룬다. 환자 진료 장소를 AI가 결정하는 기능은 구현 범위에 포함하지 않는다.

구조는 보호자 UI → 상태·권한·누락 검증 → 문의/문서/검토 도구 재현 → 변경 이력·실행 계획이다. 지도와 기관 필터는 위치·행정 정보를 제공하고 임상적 수용 가능성을 보증하지 않는다. 개발 서브에이전트는 별도 worktree에서 작업하며, 이것을 서비스의 다중 임상 Agent 구조로 설명하지 않는다.

## 3. 검증 기록

| 검사 | 명령·방법 | 결과·근거 |
| --- | --- | --- |
| 의존성 설치 | 개발 환경 `npm install --ignore-scripts` 성공 보고. 깨끗한 설치는 `npm ci` | 개발 설치 확인, 재현 설치 대기 |
| 상태·권한·보완·비용 | `npm test` | 대기 |
| 데이터 처리 | 기관명·주소·진료과·상태·날짜의 합성 입력 대조 | 대기 |
| 정적 빌드 | `npm run build` | 대기 |
| 브라우저 전체 동선 | 문의→자료→공유→접수→보완→회신→계획 | 대기 |
| 반응형·접근성 | 1440px·390px, 넘침·포커스·레이블·주요 대비 | 대기 |
| 외부 지도 실패 | 타일 미응답 상태의 설명·다른 기능 사용 | 대기 |
| 작업 관측 | `npm run observe` | 통합 담당자가 실 worktree 상태 출력 확인. 최종 작업 상태 갱신 대기 |
| 규칙 준수 eval | `npm run eval`, 소유권·계약·표시·빌드 증거 | 대기. 자동 판정 범위와 미검증 분모를 명시 |
| 비밀값·민감정보 | 소스·문서·캡처·산출 ZIP 대조 | 대기 |
| ZIP 재현 | 패키징→압축 해제→설치→실행 | 대기 |
| 센터 PC | i7-8700 / GTX 1060 / RAM 32GB, OS·브라우저·네트워크 기록 | 미실행 |

검사 기록을 채울 때 실행 환경·커밋·명령·종료 코드·개수·관측 결과를 함께 남긴다. 검사하지 않은 화면과 외부 연동에 결과를 확대 적용하지 않는다. 합성 환자 검사로 임상적 유효성을 입증하지 않는다.

## 4. 한계

- 필수 데이터 859의 메타데이터·공개 미리보기 확인과 어댑터 개발은 실제 활용·재배포 권리 확인과 다르다. 대회 필수 사용 요건은 미완료다.
- 문의·문서 제출·의료진 회신은 결정적 재현이며 실제 발신·기관 전송·임상 판단이 아니다.
- 런타임 모델과 모델별 Prompt·Tool 호출은 아직 연결하지 않았다.
- 지도 위 가상 위치는 실제 참여 기관·환자 주소가 아니다. 경로 API 없는 이동시간을 만들지 않는다.
- 비용은 사용자의 가정 입력이다. 한국 급여 적용과 환자별 본인부담·항공·숙박 견적을 검증한 결과가 아니다.
- 센터 최소사양을 고려한 가벼운 구성과 해당 PC의 실제 작동 검증을 구분한다.
- 실제 서비스에는 기관 협력, 의료진 검토, 동의·민감정보·기록 전달·외부 서비스 조건 검토가 더 필요하다.

## 5. 센터 활용 방안

센터에서는 우선 합성 사례로 데이터 후보 조회와 업무 진행 분기를 시연·교육하고, 필수 데이터 접근이 확보되면 행정 정보 변화가 문의 대상과 준비 결과에 미치는 영향을 재현한다. 운영자는 문의·자료·검토 상태와 누락 담당을 확인할 수 있는지 평가한다.

실제 환자 운영을 센터의 기본 PC 시연에 바로 연결하지 않는다. 병원·의료진·정보 처리 책임자와 검증 범위를 정한 뒤 단계적으로 운영한다. 외부 지도·모델·통신이 필요한 모드와 외부 연결 없이 가능한 시뮬레이션을 매뉴얼에서 구분한다.

## 6. 다음 검증과 개선

미완료 필수 항목은 [제출 추적표](submission-checklist.md)를 따른다. 회귀나 규칙 위반이 발견되면 담당 작업·원인·수정 커밋·재검증 결과를 하네스 기록에 남긴다. 자동 준수율을 임상·법적 타당성 또는 제품 완성도 점수로 사용하지 않는다.
