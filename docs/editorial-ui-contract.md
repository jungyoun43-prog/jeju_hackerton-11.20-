# 보호자 작업 화면 재설계 계약

2026-10-31. 사용자는 현재 화면이 ‘AI slop’처럼 보인다고 지적하고, 로고를 이미지로 제작하도록 요청했다. 기존 MVP 기능·지정 데이터 활용·AWS 배포 목표는 유지한다. 별도 디자인 선택 승인 없이 완성해 달라는 기존 위임에 따라 통합 담당자가 방향을 정한다.

## 방향

기존의 짙은 녹색 사이드바·큰 강조 카드·홍보 문장·반복 배지를 교체한다. 따뜻한 종이색 바탕, 현무암색 본문, 제한된 귤색 행동, 낮은 곡률과 얇은 구분선으로 사례와 작업을 읽게 한다. 장식용 문서 질감·가짜 번호·대시보드 지표는 만들지 않는다. 화면은 일반적인 탐색·버튼·폼으로 동작하는 업무 앱이다.

Impeccable concept-seed 실행은 `sh`로 복구했다. 후보는 가족 공유 캘린더, 한국 책의 타이포그래피, 공공 안내 체계, 돌봄 연락장의 내용 밀도, 모바일 뱅킹의 거래 목록, 가족 사진첩, 병원 안내 책자다. 배정된 네 번째 방향인 돌봄 연락장의 여백·짧은 기록·상태 구분을 사용한다 (`seed:a25f97f1d883646c`). 도구의 무작위 결과는 제품 사실이나 사용자 결정으로 표현하지 않는다. 타입 표본의 명확한 크기 차이, 공항 안내의 단일 다음 행동 원칙만 보완하며 외형은 복제하지 않는다.

첫 화면: ‘김정희 님의 진료 준비’라는 사례 제목, 보호자·제주 위치·다음 방문 정보, 현재 병목과 주 행동 하나, 양 기관의 준비 상태와 부족한 자료. 사용자가 의사 이미지가 어울리지 않는다고 재차 지적했으므로 인물 일러스트를 제거하고 헤더 높이를 줄인다. 서비스 역할은 짧게 설명하고 같은 내용을 여러 카드에서 반복하지 않는다. 자료·진행 기록·문의·일정·데이터는 기존 기능을 보존한다.

- 로고는 사용자가 지정한 에이전트 대화의 최종 혼디(hondi) 원본을 재사용한다. `/assets/hondi-logo-v1.png`는 귤 심볼+영문 lockup, `/assets/hondi-mark-v1.png`는 같은 심볼의 Agent 표시·favicon이다. 링크의 한글 접근 이름을 제공하고 중복 이미지 대체 텍스트는 비운다. 정확 프롬프트·원본·여백/축소 내보내기 범위는 manifest에 기록한다.

## 데이터 계약 정정

사용자가 AGENTS.md의 지정 데이터 활용을 재확인했다. 허브 859 공개 미리보기의 20행 분석, 폐업 7행을 제외한 기관 13곳의 최소 등록 사실을 출처·시점과 함께 실제로 사용한다. 공개 미리보기 연결에 별도 사용권이나 파일 업로드를 선행 조건으로 두지 않는다. 전체 운영 API·실시간 수용·의료진 참여는 연결하지 않았다. 원자료 전체 CSV를 재배포하거나 임의 이용허락을 주장하지 않는다. 앞선 ui-refresh-contract의 집계만 사용한다는 범위는 이 결정으로 교체한다.

수정은 전용 worktree에 커밋하며 root가 검증 후 반영한다. UI 담당자는 로고 경로를 바로 사용하되 자산 파일은 수정하지 않는다. 공통 인터페이스와 데이터 로더는 유지한다. root는 `app/app.js`를 동시에 수정하지 않는다.

## 수락 기준

1440×900·390×844에서 첫 주 행동이 보이고 가로 넘침이 없다. 실제 공개 기관 13곳을 조회·선택할 수 있고, 시연 응답과 현재 수용 여부가 구분된다. 연락·자료 보완·공유 허용·추가자료 loop·회신·동행 계산·보고서·리셋이 유지된다. PC·모바일 렌더와 독립 검토 후 AWS에서 실제 배포 SHA를 확인한다.
