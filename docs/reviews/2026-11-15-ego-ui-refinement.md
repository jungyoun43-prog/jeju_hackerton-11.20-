## 관측과 수정

- 다음 질문의 설명 자리에 이전 처리 결과가 들어가 FHIR·미연결 설명이 질문을 덮었다. 질문 설명과 앞선 선택의 처리 결과를 분리하고 결과 원문은 native details에 보존했다.
- 선택형 체험과 상단 일괄 예시가 모두 체험으로 표시됐다. `방문 준비 시작`·`직접 요청하기`·`결과 예시`로 역할을 구분했다. 직접 요청하기는 초점만 이동하며 자동 전송하지 않는다.
- 시작 전에 업무 projection의 남은11건·이동 단계 ‘지금’을 보여줬다. 첫 화면은 네 단계의 용도를 안내하고, 실제 응답 이후 기존 업무 상태·남은 일·기호를 표시한다. 상태 계산 자체는 바꾸지 않았다.
- 질문 아래 단계 상세와 대화 기록이 경쟁했다. 같은 단계 DOM을 `준비 현황과 근거`에서 펼쳐 읽고 탐색 선택·최종 준비표에서 연다. 출처 링크·기록·내용은 삭제하지 않았다.
- 체험 중 사용할 수 없는 음성·전송·글자 수가 입력 공간을 차지했다. 같은 읽기 전용 textarea는 유지하고 비활성 도구만 숨겼다. 측정한 하단 높이는 PC179→109px, 모바일175→107px다. 자유 입력 전환·안내·중지·오류는 유지한다.
- 질문/본문/선택지 폭과 여백을 정돈하고 버튼을 최소60px로 만들었다. 기존 혼디 로고·Pretendard·색·제주 배경을 유지했다.
