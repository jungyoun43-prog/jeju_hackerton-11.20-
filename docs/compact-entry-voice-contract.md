# 지역·입력 방식·부족한 조건 흐름 · 2026-11-17

이번 사용자 요청의 `제주/내륙 → 말로/글로/하나씩 → 빠진 조건 선택` 흐름이 이전 지역 선택 뒤 바로 수동 화면으로 들어가는 동작보다 우선한다. 기존 대화·자료 준비는 첫 화면의 보조 진입으로 남긴다. 투명 사진 레이어를 없애고 불투명 작업면으로 전환했다. 11월 18일 후속 피드백에 따라 지역·방식 선택은 가용 너비·높이에 맞춰 글자·여백·버튼을 함께 조절하며 내용 높이·문구 폭 CTA를 유지한다. 고정1,440px 제한은 이 기준으로 대체한다. 520px 이하에서는 짧은 두 행으로 배치한다. 요청 예시 두 개는 기본 표시하고 기존 글을 지우지 않고 덧붙이며 자동 제출하지 않는다. 다음 단계·현재 화면의 선택·보조 작업은 강조와 동사·화살표 방향으로 구분한다.

감귤 궤적과 클릭 파동은 표시만 담당한다. 다음 화면의 상태·초점을 즉시 바꾼 뒤 효과를 재생하고, 연속 클릭·탭 숨김·움직임 줄이기 설정 변경에서 이전 효과를 정리한다. 키보드 이동은 공간 애니메이션 없이 처리한다. [최신 비율·모션 확인](reviews/2026-11-18-fluid-entry-motion.md)을 따른다.

## 입력과 조건 표시

- 단일 공통 입력을 유지한다. 텍스트 입력 도중에는 외부 모델을 자동 호출하지 않고 공개 병원명·진료과·명시 날짜·시간·이동 지역을 읽는다. 모호한 상대 날짜·복수 후보·증상에서 진료과를 임의 결정하지 않는다.
- 병원·진료과, 희망 일정, 준비 서류, 이동·동행의 네 행이 입력에 따라 채워진다. 귤 심볼과 짧은 전환은 새로 찾은 조건을 알리며 실제 예약·진료 준비 완료 상태와 구분한다.
- **내용 정리** 뒤 병원·진료과·희망 날짜·의료진/시간을 확인하고 빠진 항목만 직접 선택한다. 공개 병원은 실제 등록 자료, 내륙의 시간표는 기존 가상 체험이다. 실제 기관을 기본 가상 기관으로 바꾸지 않는다.
- 수정하지 않은 선택은 보존하고 명시 취소는 해당 조건과 관련 이동 체크를 지운다. 시간 미정과 시간 무관, 휠체어 필요·불필요·미확인을 구분한다. 실제 예약 미확인이라는 고지는 희망 날짜 취소로 해석하지 않는다.
- 서류·동행 요청은 원문과 미리보기에 남긴다. 자유 문장만으로 서류 검증·동행 예약을 완료하거나 기존 임상 사례를 수정하지 않는다. 현재 텍스트 입력은 범용 AI 이해가 아닌 보수적인 조건 추출이다.

## 실시간 음성

별도 ElevenLabs 계정 없이 현재 서버의 OpenAI 키를 재사용한다. 화면에서 **실시간 대화 시작**을 누른 뒤에만 마이크를 열며, 전송 대상과 AI 음성임을 시작 전 표시한다. WebRTC의 음성 입력·음성 출력과 semantic VAD의 끼어들기를 사용한다. 음성 인식·조건 요약은 진행 중 네 행을 갱신하고, 사용자 확인 전에는 예약 상태로 적용하지 않는다.

기술 기록: 음성 `gpt-realtime-2.1`, 출력 음성 `marin`, 전사 `gpt-4o-mini-transcribe` 한국어. 일반 요청은 기존 `gpt-6.1-sol`, 추론 `medium`이다. 제품 화면·공개 capabilities에 모델명·추론 설정을 표시하지 않는다. 실시간 모델이 일반 Responses의 reasoning 설정을 공유한다고 주장하지 않는다.

- 로컬 Node의 `/api/voice/session`이 브라우저 SDP를 검증하고 서버 키로 OpenAI unified calls를 만든다. `/api/voice/end`는 해당 임시 토큰의 세션을 종료한다. 키·공급자 오류 본문·추론 내용을 응답하지 않는다.
- 기본 UTC 하루 **3회 생성 시도**, 프로세스 동시 **1개**, 세션 **최대 180초**, 응답 **최대 768토큰**. 실패한 외부 생성 시도도 차감한다. 영속 카운터는 `.runtime/realtime-usage`의 날짜·빈 번호 파일이다. 금액의 절대 상한은 아니다.
- 자동 재연결·모델 대체는 없다. 서버 타이머가 종료를 요청하며 종료가 불명확하면 추가 생성을 막는다. 브라우저는 마이크·피어를 즉시 닫고 서버의 5초 종료 대기보다 긴 최대 8초를 기다린다. 이 동안 새 시작을 막으며 종료 확인 실패를 성공으로 표시하지 않는다.
- 화면 이동·탭 숨김·새 대화·취소는 마이크를 닫고 늦은 전사·도구 응답이 새 입력을 덮지 않도록 소유권을 검사한다. 내용 정리는 종료 네트워크 응답을 기다리며 새 화면에 적용하는 동작을 하지 않는다.
- 혼디는 원음·SDP·전사를 서버 저장소에 보관하지 않는다. OpenAI로 전달되는 음성의 공급자 처리는 별도 서비스 정책의 대상이며, 공급자 무보관을 보증한 구현은 아니다.
- 현재 실시간 엔드포인트는 로컬 Node에 구현했다. 기존 AWS Lambda/S3에 배포하거나 사용자 인증·전역 동시 접속 제한을 확장한 상태는 아니다. HTTPS 운영 시 `REALTIME_ALLOWED_ORIGIN`을 정확한 출처로 설정한다.

## 접기·화면·서체

주요 선택과 다음 행동은 보이게 두고, 이용 범위·원문·공개자료 출처·다른 병원 후보·이동 문의처·항공 상세는 필요할 때 펼친다. 단계와 다음/이전 행동은 기존 고정 영역을 유지한다. 작은 화면은 내부 읽기 영역을 스크롤하며 문서 전체 가로 넘침을 막는다.

제목·지역 선택은 제주특별자치도의 **제주고딕**, 본문·입력은 기존 자체 호스팅 Pretendard를 쓴다. 원본 TTF만 추가하고 시스템 설치나 폰트 변환을 하지 않았다. 감귤은 기존 혼디 심볼 자산을 재사용하며 `prefers-reduced-motion`에서는 움직이지 않는다.

초안은 기존 제주 바다·현무암 생성 이미지를 배경으로 썼으나, 후속 사용자 피드백에 따라 진입 화면에서는 사진 위 투명 레이어를 없애고 불투명한 아이보리·초록·감귤색 면을 사용한다. Headspace의 따뜻한 색면과 주 행동 대비, Linear 공개 페이지의 정렬·정보 위계를 참고했다. 로고·사진·코드를 복사하거나 로그인 뒤 제품을 확인한 것으로 주장하지 않는다.
