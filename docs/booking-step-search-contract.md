# 단계 이동과 검색 · 2026-11-16

최신 사용자 요청에 따라 주 흐름을 병원·진료과 → 의료진·시간 → 접수 확인 → 이동·준비표로 통일한다. 상단과 오른쪽은 동일한 네 단계를 표시한다. 고정 하단에 선택 요약, 이전, 이름이 분명한 다음 행동을 둔다. 선택만으로 다음 화면으로 넘기지 않는다.

- 병원·진료과, 제주 지역은 검색과 목록 선택을 함께 제공한다. 공개 병원은 이름·주소도 검색한다. 결과가 없으면 표본의 한계를 설명한다. 외부 주소 검색이나 지오코딩을 연동한 것으로 표시하지 않는다.
- 가상 일정은 초진·의뢰서 질문 전에 조회할 수 있다. 월별 달력에서 하루/기간을 고른 뒤 의료진·시각을 선택한다. 초진·재진과 의뢰서 질문은 접수 확인 단계에 놓는다. 답변 전 요청을 막고, 의뢰서 미준비·미확인은 상담만 허용한다. 실제 예약은 수행하지 않는다.
- 공개 병원은 선택한 기관에 등록된 진료과를 별도로 지정한다. 검색 필터를 실제 선택 진료과로 혼동하지 않는다. 의료진 무관/희망 이름, 시간대/희망 시각을 받을 수 있지만 사용자 희망일 뿐 소속·일정·빈자리 확인이 아니다. 실제 병원에 합성 의료진·시간표를 붙이지 않는다.
- 뒤로가기·자료 확인은 선택값을 보존한다. 병원·진료과·희망 조건 변경은 관련 이동 확인을 재확인으로 돌린다. 검색어는 UI 임시 상태이며 전송하지 않는다. 원래 대화 DOM과 초안·안내 접근은 보존한다.
